## 🎉 1. What is Vite? {#🎉-1-vite-是什么}

Vite is a front-end building tool developed by You Yuxi (Vue author).

Core features:

| Features | Vite | Webpack |
| ------- | ------------- | --------------- |
| Development startup | Open in seconds (No-Bundle) | Slow |
| HMR hot update | Extremely fast (update by module) | Some bundles need to be rebuilt |
| Build | Rollup | Webpack package by yourself |
| Configuration complexity | Simple | Complex |

**In a word: The development speed is the fastest in the industry and the build quality is the highest.**

## 🚀 2. Get started quickly {#🚀-2-快速上手}

### ✔ Create project {#✔-创建项目}

```bash
npm create vite@latest
```

Choose a framework such as Vue/React.

### ✔ Install dependencies {#✔-安装依赖}

```bash
npm install
```

### ✔ Start the development server {#✔-启动开发服务器}

```bash
npm run dev
```

You will see:

```
Local: http://localhost:5173/
```

### ✔ Production build {#✔-生产构建}

```bash
npm run build
```

## 📁 3. Project structure description {#📁-3-项目结构说明}

```
project/
 ├── index.html ← 最独特的地方，入口文件
 ├── src/
 │    ├── main.ts
 │    ├── App.vue
 └── vite.config.ts
```

`index.html` directly controls the entry script:

```html
<script type="module" src="/src/main.ts"></script>
```

Unlike Webpack:
**Vite is centered around index.html rather than packaging entry files.**

## ⚙️ 4. Principles of Vite development model (core) {#⚙️-4-vite-开发模式原理-核心}

## ⭐ Reason 1: Not packaging development code {#⭐-原因一-不打包开发代码}

Webpack：

```
打包 → 输出 bundle → 浏览器加载
```

Vite：

```
浏览器遇到 import → Vite 返回对应文件
```

Leveraging browser-native ESM:

```js
import { createApp } from './src/main.js'
```

The browser automatically requests the environment:

```
/src/main.js
```

Vite does the most basic parsing of files (Vue, TS, React, CSS, etc.), but **Not packed** 。

### Result: startup speed is independent of project size → starts in seconds {#结果-启动速度与项目大小无关-→-秒开}

## ⭐ Reason 2: Ultra-fast HMR {#⭐-原因二-超快-hmr}

Updating a file → reloads only the file, not the entire bundle.

Vue single file component updates are basically at the millisecond level.

## 🏗 5. Vite construction mode principle (Rollup) {#🏗-5-vite-构建模式原理-rollup}

When building for production:

* Tree Shaking
* code splitting
* CSS extraction
* Chunk split
* Compression Minify
* Assets processing

Delegate it all to **Rollup** (the best optimized bundler in the industry).

## 🔧 6. Detailed explanation of Vite configuration file (vite.config.ts) {#🔧-6-vite-配置文件详解-vite-config-ts}

The most basic:

```ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
})
```

Below are the configuration points from beginner to advanced.

## ✅ Commonly used configuration points {#✅-常用配置点}

### 1. alias alias {#_1-别名-alias}

```ts
resolve: {
  alias: {
    '@': '/src'
  }
}
```

### 2. environment variables {#_2-环境变量}

Added `.env.development` / `.env.production`:

```
VITE_API_URL=https://xxx.com
```

Use:

```js
import.meta.env.VITE_API_URL
```

### 3. Server proxy (solve cross-domain) {#_3-服务器代理-解决跨域}

```ts
server: {
  proxy: {
    '/api': {
      target: 'https://backend.com',
      changeOrigin: true,
      rewrite: p => p.replace(/^\/api/, '')
    }
  }
}
```

### 4. Static resources {#_4-静态资源}

If placed in the `public/` root directory, it will not be packaged and will be copied directly as it is.

### 5. CSS and preprocessors {#_5-css-与预处理器}

Support:

```ts
css: {
  preprocessorOptions: {
    scss: {
      additionalData: `@import "@/styles/global.scss";`
    }
  }
}
```

### 6. Build optimization {#_6-构建优化}

```ts
build: {
  sourcemap: false,
  minify: 'esbuild',
  rollupOptions: {
    output: {
      manualChunks: {
        vendor: ['vue']
      }
    }
  }
}
```

## 🔌 7. Vite plug-in system (from getting started to being able to write) {#🔌-7-vite-插件体系-从入门到会写}

The plug-in follows the Rollup specification + Vite exclusive Hook.

## The simplest plug-in {#最简单插件}

```ts
export default function MyPlugin() {
  return {
    name: "my-plugin",
    transform(code, id) {
      if (id.endsWith('.js')) {
        return code.replace('hello', 'hi')
      }
    }
  }
}
```

## Plug-in capabilities include: {#插件能力包括}

* transform (compiled code)
* load (load file)
* resolveId (custom path)
* handleHotUpdate（HMR）
* configureServer (middleware)

Vite can write:

* Automatic import plugin
* Mock service plug-in
* Single file component loader
* Custom backend proxy

Use `manualChunks` or `dynamic import()`.

## 🚀 10. Performance optimization {#🚀-10-性能优化}

## development environment {#开发环境}

* Disable redundant plugins
* Pre-build large dependencies (optimizeDeps)

```ts
optimizeDeps: {
  include: ['lodash-es']
}
```

## production environment {#生产环境}

* gzip/brotli compression
* Multi-core packaging (using esbuild)
* Precise subcontracting (manualChunks)
* CDN acceleration
