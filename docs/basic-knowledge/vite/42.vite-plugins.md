Write a Vite plug-in that actually works


## **Function: Automatically remove `console.log` in the code when compiling** {#功能-自动将代码中的-console-log-编译时移除}

For example:

```js
console.log("hello")
```

After building it becomes:

```js
// 被移除
```

You will learn:

* Plug-in structure
* Vite plug-in life cycle
* transform hook
* Process file ID
* Hot update behavior

Then gradually upgrade the plug-in.

## 📌 Step 1: Basic structure of the plug-in {#📌-step-1-插件的基础结构}

A Vite plugin is essentially a **function returns an object** ：

```ts
export default function myPlugin() {
  return {
    name: 'my-plugin',
  }
}
```

This is the most basic plugin structure for Vite.

## 📌 Step 2: Understand the plug-in life cycle {#📌-step-2-理解插件生命周期}

Vite plug-in API = Rollup plug-in + Vite's own extension.

The hooks you will use most often are these:

| hook | function |
| --------------- | ---------------- |
| config | Modify Vite configuration |
| configureServer | dev server middleware |
| resolveId | path resolution |
| load | custom content return |
| transform | **Modify the core hook of the source code** |
| handleHotUpdate | HMR              |

We just need transform now.

## 📌 Step 3: Implement transform() processing code {#📌-step-3-实现-transform-处理代码}

Our goal: remove `console.log(...)`.

The transform hook will accept two parameters:

```ts
transform(code, id) { ... }
```

* **code**: source code of the current file
* **id**: including path, query, style suffix, etc., for example:

```
/src/main.js?import
```

## ✔ Implement plug-in function (first version) {#✔-实现插件功能-初版}

Create `plugins/remove-console.js` at the project root:

```js
export default function removeConsole() {
  return {
    name: 'vite-plugin-remove-console',

    transform(code, id) {
      if (!id.endsWith('.js') && !id.endsWith('.ts')) return;

      // 简单替换逻辑
      const transformed = code.replace(/console\.log\(.*?\);?/g, '')

      return {
        code: transformed,
        map: null, // 可选：不生成 sourcemap
      }
    }
  }
}
```

## 📌 Step 4: Use plugins in Vite {#📌-step-4-在-vite-中使用插件}

`vite.config.js`：

```js
import removeConsole from './plugins/remove-console.js'

export default {
  plugins: [
    removeConsole()
  ]
}
```

Start the project:

```
npm run dev
```

Open the console and you will see that all `console.log` has been removed during the compilation phase.

## 📢 You now know how to write a basic Vite plugin {#📢-你现在已经会写一个基础-vite-插件了}

Let's continue upgrading and let you enter the real "plug-in developer" level.

## ⭐ Step 5: Support multiple console methods (more professional) {#⭐-step-5-支持多种-console-方法-更专业}

For example:

* console.info
* console.debug
* console.warn
* console.error (optional)

Use regular expressions:

```js
const regex = /console\.(log|info|debug)\(.*?\);?/g
```

Modify the plugin:

```js
const transformed = code.replace(
  /console\.(log|info|debug)\(.*?\);?/g,
  ''
)
```

## ⭐ Step 6: Remove console only in production environment {#⭐-step-6-只在生产环境移除-console}

```js
export default function removeConsole() {
  return {
    name: 'vite-plugin-remove-console',

    apply: 'build', // 仅在 build 阶段启用

    transform(code, id) {
      if (!id.match(/\.(js|ts)$/)) return

      return code.replace(
        /console\.(log|info|debug)\(.*?\);?/g,
        ''
      )
    }
  }
}
```

## ⭐ Step 7: Support user-defined configuration (required for professional plug-ins) {#⭐-step-7-支持用户自定义配置-专业插件必备}

Make plugins more flexible:

```js
export default function removeConsole(options = {}) {
  const methods = options.methods || ['log', 'info', 'debug']

  const reg = new RegExp(`console\\.(${methods.join('|')})\\(.*?\\);?`, 'g')

  return {
    name: 'vite-plugin-remove-console',

    apply: 'build',

    transform(code, id) {
      if (!id.match(/\.(js|ts)$/)) return
      return code.replace(reg, '')
    }
  }
}
```

Users use this:

```js
removeConsole({
  methods: ['log', 'debug']
})
```

## ⭐ Step 8: Support sourcemap (advanced) {#⭐-step-8-支持-sourcemap-进阶}

Return:

```js
return {
  code: transformed,
  map: this.getCombinedSourcemap()
}
```

## ⭐ Step 9: Support HMR (optional) {#⭐-step-9-支持-hmr-选学}

If you remove the console in dev mode too, HMR needs to be consistent.

```js
handleHotUpdate(ctx) {
  console.log('File changed:', ctx.file)
}
```

```

 ├─ index.js
 ├─ package.json
 ├─ README.md
 └─ LICENSE
```

`index.js`：

```js
export default function removeConsole(options = {}) {
  const methods = options.methods || ['log', 'info', 'debug']

  const reg = new RegExp(
    `console\\.(${methods.join('|')})\\(.*?\\);?`,
    'g'
  )

  return {
    name: 'vite-plugin-remove-console',
    apply: options.apply || 'build',

    transform(code, id) {
      if (!id.match(/\.(js|ts)$/)) return

      const transformed = code.replace(reg, '')

      return {
        code: transformed,
        map: null,
      }
    }
  }
}
```
