## 1\. How search engines work {#一、搜索引擎工作原理}

### 1️⃣ Crawling {#_1️⃣-crawling-抓取}

#### ✔ Essence {#✔-本质}

Search engines continuously visit web pages through crawlers (such as Googlebot) to build a "candidate page pool".


### ✔ Priority of robots.txt {#✔-robots-txt-的优先级}

👉 Actual rules:

| Priority | Rules |
| --- | ------------------------- |
| 1 | robots.txt (whether to allow crawling) |
| 2 | meta robots (page-level control) |
| 3   | HTTP Header（X-Robots-Tag） |


#### ✔ robots.txt common misunderstandings {#✔-robots-txt-常见误区}

❌ Misunderstanding:

> Disallow = Page will not be included

✅Actual:

* Disallow = **Do not crawl**
* But it may still be indexed (discovered through external links)

👉 Want not to include it at all:

```html
<meta name="robots" content="noindex" />
```


### ✔ Crawling frequency (Crawl Budget) {#✔-抓取频率-crawl-budget}

👉 Every website has a “crawl budget”

Influencing factors:

* Website authority (Authority)
* update frequency
* Number of pages
* Server response speed


#### ✔ How to observe? {#✔-如何观察}

Using Google Search Console:

Path:

* Settings → Crawl stats

You can see:

* Crawl times per day
* response time
* Crawl file types


### 🔥 Advanced Tips {#🔥-高级技巧}

👉 Improve crawling efficiency:

* Reasonable internal links (important!)
* Provide sitemap.xml
* Avoid dead links
* SSR provides full HTML


## 2\. Indexing {#二、indexing-索引}

### ✔ Core cognition {#✔-核心认知}

> Search engines don’t “read web pages” directly, but “look at index libraries”


### ✔ "Inclusion ≠ Ranking" (must be able to speak) {#✔-收录-排名-必须会说}

| Stage | Meaning |
| ----------- | ---------- |
| Indexed | The page enters the database |
| Ranking | Whether to display + Ranking |

👉 Example:

* Page included ✔
* But on page 100 ❌


### ✔ Key factors affecting indexing {#✔-影响索引的关键因素}

#### 1. Content quality {#_1-内容质量}

* Is it original?
* Is it valuable?


#### 2. Page parsability {#_2-页面可解析性}

❗ CSR issues:

```html
<div id="root"></div>
```

👉 Almost an “empty page” to crawlers


#### 3. Deduplication mechanism (very critical) {#_3-去重机制-非常关键}

Search engines will automatically determine:

* Is the content duplicated?
* Do you need to combine weights?


### ✔ What canonical really does {#✔-canonical-的真正作用}

👉 Tell search engines:

> Which URL is the "master version"

```html
<link rel="canonical" href="https://example.com/page" />
```


### 🔥 Advanced understanding {#🔥-高级理解}

canonical ≠ mandatory instruction
👉 It’s a “suggestion”, search engines don’t have to listen to it


## 3\. Ranking {#三、ranking-排名}

### ✔ Three core elements of ranking {#✔-排名核心三要素}


#### 1️⃣ Keyword Relevance (Relevance) {#_1️⃣-关键词相关性-relevance}

👉 What are search engines doing?

> “Is this page answering a user question?”

Matching dimensions:

* title
* h1
* Text
* Semantics (NLP)


#### 2️⃣Authority {#_2️⃣-权重-authority}

👉 Source:

* Backlinks
* Website history
* Brand trust


### ✔ Link Juice (weight flow) {#✔-link-juice-权重流动}

👉 Concept:

> Page authority is passed through links


#### ✔ Example: {#✔-示例}

```
A页面（权重高） → B页面
```

👉B page weight will increase


#### ✔ Internal link optimization (practical focus) {#✔-内链优化-实战重点}

* Home Page → Core Page
* Links between articles
* Avoid island pages


### 🔥Advanced point: weight dispersion {#🔥-高级点-权重分散}

```
A → B
A → C
```

👉 The weight is "divided"


## 4\. The SEO value of semantic HTML (in-depth version) {#四、语义化-html-的-seo-价值-深入版}

### ✔ Why is semantics important? {#✔-为什么语义化很重要}

Because crawlers cannot "visually understand" and can only rely on structural judgment.


### ✔ Recommended structure {#✔-推荐结构}

```html
<main>
  <article>
    <h1>文章标题</h1>
    <section>内容</section>
  </article>
  <aside>推荐内容</aside>
</main>
```


### ✔ Tag semantic role {#✔-标签语义作用}

| Tags | SEO role |
| ----------- | ----- |
| `<main>` | Main content |
| `<article>` | Independent content block |
| `<nav>` | Navigation structure |
| `<aside>` | Auxiliary content |


### ✔ Value to crawlers {#✔-对爬虫的价值}

👉 Help it quickly judge:

* Where is the text
* where is navigation
* Where is advertising


### ❗ Common mistakes {#❗-常见错误}

```html
<div class="title">xxx</div>
```

👉 ❌ SEO fails to recognize importance


## 5\. Heading system {#五、heading-体系}

### ✔ Standard rules {#✔-标准规则}

* 1 page → **There can be only one `<h1>`**
* Hierarchical progression:

```
h1 → h2 → h3
```


### ✔ SEO Essence {#✔-seo-本质}

👉 Heading is the "content structure tree"


### ✔ Best Practices {#✔-最佳实践}

```html
<h1>Next.js SEO 完整指南</h1>
<h2>什么是 SEO</h2>
<h3>定义</h3>
```


### ❗ Common pitfalls {#❗-常见坑}

* Replace semantics with style ❌
* Multiple h1 ❌ (tolerated by search engines now, but not recommended)


## 6\. Sitemap.xml (site map) {#六、sitemap-xml-站点地图}

### ✔ Essence {#✔-本质-1}

> Tell search engines: What pages do I have?


### ✔ Example {#✔-示例-1}

```xml
<url>
  <loc>https://example.com/blog</loc>
  <lastmod>2026-03-01</lastmod>
  <priority>0.8</priority>
</url>
```


### ✔ Field explanation {#✔-字段解释}

| Field | Function |
| -------- | ---- |
| loc | page address |
| lastmod | update time |
| priority | priority |


### ❗ Important knowledge {#❗-重要认知}

👉 priority ≠ ranking weight
Just "Fetch Suggestions"


### ✔ Practical suggestions {#✔-实战建议}

* Automatically generated (Next.js/CMS)
* Automatically refresh when updating


## 7\. Canonical (anti-duplication core mechanism) {#七、canonical-防重复核心机制}

### ✔ Why is it needed? {#✔-为什么需要}

Avoid:

```
example.com
example.com?ref=ads
example.com?page=1
```

👉 Treated as multiple pages → weights dispersed ❌


### ✔ Standard writing {#✔-标准写法}

```html
<link rel="canonical" href="https://example.com" />
```


### ✔ Summary of functions {#✔-作用总结}

* Combined weights
* avoid duplicate content
* Improve ranking stability


### 🔥 Advanced scenes {#🔥-高级场景}

#### ✔ Pagination SEO {#✔-分页-seo}

```
?page=1
?page=2
```

👉 canonical points to:

* First page or yourself (see strategy)


#### ✔Multi-language site {#✔-多语言站点}

Combine:

* canonical
* hreflang


## 8\. How does SEO work? {#八、-seo-工作原理是什么}


-  Search engines are mainly divided into three stages: crawling, indexing, and ranking.
-  The crawling phase is controlled by robots.txt and crawl budget;
-  The core of the indexing phase is content quality and deduplication mechanism (canonical);
-  The ranking stage is determined by keyword relevance and weight (link juice).
-  At the front-end level, I mainly optimize technical SEO through SSR, semantic HTML, heading structure, sitemap and canonical.
