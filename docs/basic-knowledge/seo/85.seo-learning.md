## 1\. The essence of SEO: What problem is it solving? {#一、seo-本质-它到底在解决什么问题}

The core goals of SEO (Search Engine Optimization) are:

> **Make your page easier to be discovered + understood + ranked higher by search engines**

The result is:

* More **organic traffic**
* higher conversion rate
* Lower customer acquisition cost ([Next.js][1])


## 2\. Search engine workflow {#二、搜索引擎工作流程}

The following stages are a useful model; JavaScript rendering participates in indexing, so this is not a strict one-pass sequence:

### 1️⃣ Crawling {#_1️⃣-crawling-抓取}

Search engine bots (such as Googlebot) visit your website

Influencing factors:

* sitemap.xml
* robots.txt
* Internal link structure


### 2️⃣ Indexing {#_2️⃣-indexing-索引}

Save page content to database

Influencing factors:

* Is the HTML readable (SSR vs CSR)?
* Does the page content actually exist?


### 3️⃣ Rendering {#_3️⃣-rendering-渲染}

Parse JS and generate the final page (critical for SPA)

👉 CSR issues:

* The initial HTML is an empty shell
* Affect crawling efficiency

👉 Next.js advantages:

* SSR/SSG provides full HTML


### 4️⃣ Ranking {#_4️⃣-ranking-排名}

Search engines determine where you rank

Influencing factors:

* Content quality
* keyword matching
* Page Performance (Core Web Vitals)


## 3\. SEO core three systems {#三、seo-核心三大体系}

You can divide SEO into three tiers:


### 1️⃣ Content SEO (Content SEO) {#_1️⃣-内容-seo-content-seo}

Essence: **Is the content you write worthy of being recommended**

Key points:

* Keyword
* Title
* Description
* Content depth

👉 Example:

```html
<title>Next.js SEO 完整指南</title>
<meta name="description" content="详细讲解 Next.js SEO优化..." />
```


### 2️⃣Technical SEO⭐ {#_2️⃣-技术-seo-technical-seo-⭐}

The core of Next.js tutorial lies here

#### ✔ Rendering strategy {#✔-渲染策略}

| Method | SEO Effect |
| --- | ----- |
| CSR | Depends on JavaScript execution; verify crawlable content |
| SSR | Provides initial HTML; content, status codes, and links must still be correct |
| SSG | Provides prebuilt HTML; keep content up to date |

Reason:

* Search engines can more easily read HTML ([devscriptive.com][2])


#### ✔ Page structure {#✔-页面结构}

* Semantic HTML (h1~h6)
* Reasonable DOM structure
* Accessibility (a11y)


#### ✔ URL design {#✔-url-设计}

* clear path

```
/blog/nextjs-seo
```

* Avoid:

```
?id=123
```


#### ✔ Sitemap + Robots

* sitemap.xml → tells search engines which pages are there
* robots.txt → Control crawler behavior ([swiftorial.com][3])


#### ✔ Metadata (Core) {#✔-metadata-核心}

Next.js Highlights:

```js
export const metadata = {
  title: 'xxx',
  description: 'xxx'
}
```

Function:

* Can influence search appearance; search engines may rewrite titles or snippets
* Impact on click-through rate


#### ✔ Structured data (Schema) {#✔-结构化数据-schema}

* JSON-LD: describes structured data supported by search engines
* Open Graph: primarily controls social previews and is configured separately from search structured data

👉 Improvement:

* Rich text search results (Rich Snippets)


### 3️⃣Performance SEO {#_3️⃣-性能-seo-performance-seo}

👉 Google has made it clear: **Performance affects ranking**

Core Web Vitals:

| Indicator | Meaning |
| --- | ----- |
| LCP | Loading speed |
| INP | Interaction responsiveness |
| CLS | Page Stability |


#### ✔ Tool: Lighthouse {#✔-工具-lighthouse}

* Automatically detect SEO/performance issues
* Give optimization suggestions ([Next.js][4])


## 4\. Why is Next.js naturally SEO friendly? {#四、next-js-为什么天然-seo-友好}


> **Next.js = A collection of best practices for technical SEO**


### 1️⃣ SSR (Server Side Rendering) {#_1️⃣-ssr-服务端渲染}

Advantages:

* HTML complete
* Search engines can read it directly


### 2️⃣ SSG / ISR

Advantages:

* Super fast loading (CDN)
* Also keep content updated ([devscriptive.com][2])


### 3️⃣ Image optimization {#_3️⃣-image-优化}

Next.js automatically:

* lazy load
* WebP
* size fit

👉 Improve LCP


### 4️⃣ Automatically optimize performance {#_4️⃣-自动优化性能}

* code splitting
* cache
* Edge/CDN

👉 Technical SEO + Performance SEO solved together


## 5\. An “Advanced Cognition” {#五、一个-高级认知}

👉 SEO ≠ Technology

Real ranking core:

> **Content + Authority + User Experience**

Technical SEO is just “infrastructure”


A very true point of view from the community:

> Lighthouse score ≠ ranking
> What really affects SEO is content and relevancy ([Reddit][5])
