## Cesium from Beginner to Master: A Practical Guide {#cesium-从入门到精通-实战指南}

### Introduction {#引言}

In the field of web visualization, if you need to build **3D earth, digital twin city, satellite orbit visualization or GIS system**, there is a very powerful tool - CesiumJS.

Cesium is an **open source JavaScript 3D map engine** built on **WebGL** that can render high-performance **3D earth and spatial data** in the browser.Originally developed by Cesium, it is now widely used in:

- 🌍 GIS Geographic Information System
- 🛰 Satellite orbit visualization
- 🏙 Digital Twin City
- 🚗 Traffic simulation system
- 🌦 Meteorological and environmental data visualization
- 🏗 Urban planning and architectural display

Many large-scale projects, such as smart cities and digital earth platforms, combine:

- CesiumJS
- Three.js
- Mapbox GL JS

Work together to build complex **3D GIS visualization systems**.

This article is for **beginners to intermediate developers**. It will start from **Environment Building → Basic Concepts → Practical Projects → Advanced Applications → Performance Optimization**, and will take you step by step to master Cesium, and finally be able to **independently develop a 3D map project**.


## 1\. Environmental preparation {#一、环境准备}

### 1 Install Node.js and npm {#_1-安装-node-js-和-npm}

First install Node.js (LTS version recommended).

Check after installation is complete:

```bash
node -v
npm -v
```

If the version number can be output, the installation is successful.


### 2 Introducing Cesium through CDN {#_2-通过-cdn-引入-cesium}

The fastest way is to use a CDN.

Create `index.html`:

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>Cesium Demo</title>

    <script src="https://unpkg.com/cesium/Build/Cesium/Cesium.js"></script>

      rel="stylesheet"
    />

    <style>
      html,
      body,
      #cesiumContainer {
        width: 100%;
        height: 100%;
        margin: 0;
        padding: 0;
      }
    </style>
  </head>

  <body>
    <div id="cesiumContainer"></div>

    <script></script>
  </body>
</html>
```


### 3 Install via npm {#_3-通过-npm-安装}

Suitable for **engineering development**.

npm install cesium

## 2\. Basic concepts of Cesium {#二、cesium-基础概念}

Cesium has several core objects that need to be understood.


### 1 Viewer

Viewer is **Cesium entry object** 。

It contains:

- Scene
- Camera
- Imagery
- Entity

Create Viewer:

```javascript
const viewer = new Cesium.Viewer("cesiumContainer");
```

This line of code will:

- Create a 3D Earth
- Load default image
- Initialize camera control


### 2 Scene

Scene means **Entire 3D scene** 。

```javascript
const scene = viewer.scene;
```

Scene management:

- earth
- light
- rendering


### 3 Camera

Camera controls **View and Flight**.

For example, flying to Beijing:

```javascript
viewer.camera.flyTo({
  destination: Cesium.Cartesian3.fromDegrees(116.39, 39.9, 100000),
});
```

Parameter description:

| Parameters | Meaning |
| --------- | ---- |
| longitude | longitude |
| latitude | latitude |
| height | height |


### 4 Entity

Entity is a **Cesium data object**.

For example, add a point:

```javascript
viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(116.39, 39.9),
  point: {
    pixelSize: 10,
    color: Cesium.Color.RED,
  },
});
```


### 5 ImageryProvider

ImageryProvider is used to load **map images**.

For example to load an image:

```javascript
viewer.imageryLayers.addImageryProvider(
  new Cesium.UrlTemplateImageryProvider({
    url: "https://tile.openstreetmap.org/{z}/{x}/{y}.png",
  }),
);
```


## 3\. Getting Started: Creating a 3D Earth {#三、入门实战-创建-3d-地球}

Let's build a **complete 3D Earth example**.

### Complete code {#完整代码}

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>3D Earth Demo</title>

    <!-- 锁定到稳定版本，避免 API 变更导致报错 -->
    <script src="https://unpkg.com/cesium@1.95.0/Build/Cesium/Cesium.js"></script>
    <link
      href="https://unpkg.com/cesium@1.95.0/Build/Cesium/Widgets/widgets.css"
      rel="stylesheet"
    />

    <style>
      * {
        margin: 0;
        padding: 0;
        box-sizing: border-box;
      }
      html,
      body {
        width: 100%;
        height: 100%;
        overflow: hidden;
      }
      #cesiumContainer {
        width: 100%;
        height: 100vh;
      }

      #toolbar {
        position: absolute;
        top: 10px;
        left: 50%;
        transform: translateX(-50%);
        background: rgba(0, 0, 0, 0.6);
        color: #fff;
        padding: 8px 16px;
        border-radius: 6px;
        font-family: sans-serif;
        font-size: 14px;
        pointer-events: none;
      }
    </style>
  </head>

  <body>
    <div id="cesiumContainer"></div>
    <div id="toolbar">3D 地球演示 — 点击实体查看信息</div>

    <script>
      // -------------------------------------------------------
      // 1. 使用 ArcGIS 公开影像服务（无需 Token）
      // -------------------------------------------------------
      const imageryProvider = new Cesium.ArcGisMapServerImageryProvider({
        url: "https://services.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer",
      });

      // -------------------------------------------------------
      // 2. 创建 Viewer
      //    terrainProvider 使用椭球体（无需 Cesium Ion Token）
      // -------------------------------------------------------
      const viewer = new Cesium.Viewer("cesiumContainer", {
        imageryProvider: imageryProvider,
        terrainProvider: new Cesium.EllipsoidTerrainProvider(),
        baseLayerPicker: false,
        geocoder: false,
        homeButton: true,
        sceneModePicker: true,
        navigationHelpButton: false,
        animation: false,
        timeline: false,
        fullscreenButton: true,
      });

      // 开启大气层 & 光照效果
      viewer.scene.globe.enableLighting = true;
      viewer.scene.skyAtmosphere.show = true;

      // -------------------------------------------------------
      // 3. 添加标注实体
      // -------------------------------------------------------
      const cities = [
        { name: "北京", lon: 116.39, lat: 39.9, color: Cesium.Color.YELLOW },
        { name: "上海", lon: 121.47, lat: 31.23, color: Cesium.Color.CYAN },
        { name: "广州", lon: 113.26, lat: 23.13, color: Cesium.Color.LIME },
        { name: "成都", lon: 104.06, lat: 30.67, color: Cesium.Color.ORANGE },
      ];

      cities.forEach(({ name, lon, lat, color }) => {
        viewer.entities.add({
          name: name,
          position: Cesium.Cartesian3.fromDegrees(lon, lat, 0),
          point: {
            pixelSize: 12,
            color: color,
            outlineColor: Cesium.Color.WHITE,
            outlineWidth: 2,
            heightReference: Cesium.HeightReference.CLAMP_TO_GROUND,
          },
          label: {
            text: name,
            font: "bold 14px sans-serif",
            fillColor: Cesium.Color.WHITE,
            style: Cesium.LabelStyle.FILL_AND_OUTLINE,
            outlineWidth: 2,
            outlineColor: Cesium.Color.BLACK,
            verticalOrigin: Cesium.VerticalOrigin.BOTTOM,
            pixelOffset: new Cesium.Cartesian2(0, -18),
            heightReference: Cesium.HeightReference.CLAMP_TO_GROUND,
          },
        });
      });

      // -------------------------------------------------------
      // 4. 镜头飞到初始视角（俯瞰中国）
      // -------------------------------------------------------
      viewer.camera.flyTo({
        destination: Cesium.Cartesian3.fromDegrees(105, 35, 6000000),
        orientation: {
          heading: Cesium.Math.toRadians(0),
          pitch: Cesium.Math.toRadians(-45),
          roll: 0.0,
        },
        duration: 3,
      });

      // -------------------------------------------------------
      // 5. 点击实体弹出信息框
      // -------------------------------------------------------
      viewer.screenSpaceEventHandler.setInputAction((click) => {
        const picked = viewer.scene.pick(click.position);
        if (Cesium.defined(picked) && Cesium.defined(picked.id)) {
          viewer.selectedEntity = picked.id;
        }
      }, Cesium.ScreenSpaceEventType.LEFT_CLICK);
    </script>
  </body>
</html>
```

## 4\. Intermediate Advanced {#四、中级进阶}

### 1 Load 3D model (glTF) {#_1-加载-3d-模型-gltf}

Cesium supports the **glTF model**.

```javascript
viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(116.39, 39.9),
  model: {
    uri: "model.gltf",
    scale: 1,
  },
});
```

Note:

- glTF path must be correct
- The model size needs to be adjusted to scale


### 2 Load GeoJSON {#_2-加载-geojson}

Much GIS data is GeoJSON.

```javascript
Cesium.GeoJsonDataSource.load("data.geojson").then(function (dataSource) {
  viewer.dataSources.add(dataSource);
});
```

GeoJSON example:

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [116.39, 39.9]
      }
    }
  ]
}
```


### 3 Custom materials {#_3-自定义材质}

You can set materials for objects.

```javascript
viewer.entities.add({
  polygon: {
    hierarchy: Cesium.Cartesian3.fromDegreesArray([
      116, 39, 117, 39, 117, 40, 116, 40,
    ]),
    material: Cesium.Color.BLUE.withAlpha(0.5),
  },
});
```


### FAQ {#常见问题}

#### The model cannot be seen {#模型看不到}

Possible reasons:

- Model path error
- Wrong height
- scale is too small


#### GeoJSON does not display {#geojson-不显示}

Possible reasons:

- Coordinate system is not WGS84
- wrong file path


## 5\. Advanced practice: city simulation system {#五、高级实战-城市模拟系统}

A typical project may include:

- urban architecture
- real time data
- Trajectory animation


### 1 Load KML {#_1-加载-kml}

```javascript
viewer.dataSources.add(Cesium.KmlDataSource.load("city.kml"));
```


### 2 Load CZML {#_2-加载-czml}

CZML is used for **time series data**.

Such as satellite orbits.

```javascript
viewer.dataSources.add(Cesium.CzmlDataSource.load("orbit.czml"));
```


### 3 Real-time data visualization {#_3-实时数据可视化}

Data can be updated via WebSocket:

```javascript
socket.onmessage = function (event) {
  const data = JSON.parse(event.data);

  viewer.entities.add({
    position: Cesium.Cartesian3.fromDegrees(data.lon, data.lat),
    point: {
      pixelSize: 8,
    },
  });
};
```


### 4 Performance optimization {#_4-性能优化}

#### LOD (Level of Detail) {#lod-层级细节}

Load low-precision models from a distance.

Load high-precision models nearby.


#### Clustering

A large number of points need to be aggregated:

```javascript
dataSource.clustering.enabled = true;
```

## 6\. Best Practices and Debugging {#六、最佳实践和调试}

### Common mistakes {#常见错误}

#### 1 Coordinate system error {#_1-坐标系错误}

Cesium uses:

```
WGS84
```

Many China maps use:

```
GCJ02
```

Need to convert.


#### 2 Performance bottleneck {#_2-性能瓶颈}

Avoid:

```
一次加载 10 万 entity
```

Suggestions:

- Use primitive
- Using 3D Tiles


### WebGL Debugging Tools {#webgl-调试工具}

Recommended:

- Chrome WebGL Inspector
- Spector.js
