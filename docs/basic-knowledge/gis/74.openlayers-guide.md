## 1\. Introduction and positioning {#一、前言与定位}

In the field of WebGIS development, if you need to build **professional-level 2D map applications**, there is a very mature and powerful tool - OpenLayers.

**OpenLayers** is an open source JavaScript map library mainly used for building **2D GIS applications in the browser**.It supports a rich set of **map projections, vector data, and OGC services (WMS/WFS/WMTS)** and is a very common technology selection in enterprise-level WebGIS platforms.

#### Compare with other map libraries {#与其他地图库对比}

| Technology | Features | Applicable scenarios |
| ------------ | ---------------------- | ----------- |
| OpenLayers | The most powerful, supporting complex GIS | WebGIS platform |
| Leaflet | Lightweight and simple | Simple map |
| Mapbox GL JS | High-performance vector tiles | Map products |
| CesiumJS | 3D Earth Engine | Digital Twin |

Brief summary:

```
OpenLayers = WebGIS 工程
Leaflet = 轻量地图
MapboxGL = 高性能地图
Cesium = 3D 地球
```

#### 2025-2026 latest version features {#_2025-2026-最新版本特点}

OpenLayers v10.x brings several important upgrades:

- Complete **ESM Modular**

## 3\. Quick overview of core concepts {#三、核心概念速览}

**Map** is a map object.

```javascript
import Map from "ol/Map";

const map = new Map();
```


### View

**View** Controls the map perspective.

```javascript
import View from "ol/View";

const view = new View({
  center: [0, 0],
  zoom: 2,
});
```


### Layer

Map layer.

Common types:

- `TileLayer`
- `VectorLayer`
- `ImageLayer`

Example:

```javascript
import TileLayer from "ol/layer/Tile";
```

For example:

## 4\. Getting Started: Make the first map in 5 minutes {#四、入门实战-5-分钟做第一个地图}

#### main.js

```javascript
import Map from "ol/Map";
import View from "ol/View";

import TileLayer from "ol/layer/Tile";
import OSM from "ol/source/OSM";

import { fromLonLat } from "ol/proj";

const map = new Map({
  target: "map",

  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],

  view: new View({
    center: fromLonLat([121.47, 31.23]),
    zoom: 10,
  }),
});
```

After running you can see:

```
OpenStreetMap 地图
```


### Add controls {#添加控件}

```javascript
import { ScaleLine, MousePosition } from "ol/control";
```

Add:

```javascript
map.addControl(new ScaleLine());
map.addControl(new MousePosition());
```


## 5\. Intermediate Advanced {#五、中级进阶}

### 5.1 Multiple basemaps {#_5-1-多底图}

XYZ example:

```javascript
import XYZ from "ol/source/XYZ";

new TileLayer({
  source: new XYZ({
    url: "https://tile.openstreetmap.org/{z}/{x}/{y}.png",
  }),
});
```


#### ⚠ NOTE {#⚠-注意}

Domestic maps require **Coordinate System Conversion (GCJ02)**.


### 5.2 WMS service {#_5-2-wms-服务}

```javascript
import TileWMS from "ol/source/TileWMS";

new TileLayer({
  source: new TileWMS({
    url: "http://localhost:8080/geoserver/wms",

    params: {
      LAYERS: "topp:states",
    },
  }),
});
```
