# 1\. Basic principles of GIS {#一、gis-基础原理}

## 1 What is GIS?What are the core components? {#_1-什么是-gis-核心组成是什么}

Standard answer:

GIS (Geographic Information System) is used for **Systems for collecting, storing, analyzing and visualizing spatial data** 。

Three core parts:

```
空间数据
空间分析
空间可视化
```

Data structure:

```
Geometry + Properties
```

For example:

```json
{
 "type":"Point",
 "coordinates":[116.39,39.90],
 "properties":{
   "city":"北京"
 }
}
```


## 2 What is the difference between vector data and raster data? {#_2-矢量数据和栅格数据区别}

**Vector Data**

```
点
线
面
```

For example:

```
城市
道路
行政区
```

Common formats:

```
GeoJSON
Shapefile
TopoJSON
```

**Raster Data**

Essence:

```
图片
```

For example:

```
卫星图
热力图
DEM高程
```


## 3 What is the GeoJSON structure? {#_3-geojson-结构是什么}

GeoJSON is the most common GIS data format.

Type:

```
Point
LineString
Polygon
MultiPolygon
Feature
FeatureCollection
```

Example:

```json
{
 "type": "Feature",
 "geometry": {
   "type": "Point",
   "coordinates": [116.39,39.90]
 },
 "properties": {
   "name": "Beijing"
 }
}
```


# 2\. Coordinate system (GIS core) {#二、坐标系统-gis-核心}

## 4 What is the difference between WGS84, GCJ02 and BD09? {#_4-wgs84、gcj02、bd09-区别}

Three coordinate systems:

| Coordinate system | Use |
| ----- | ----- |
| WGS84 | GPS   |
| GCJ02 | AutoNavi Tencent |

China map requires:

```

```

For example:

```

```


## 5 Why is coordinate projection needed? {#_5-为什么需要坐标投影}

Reason:

```
地球是球体
屏幕是平面
```

Requires:

```
Projection
```

Common projections:

```
Web Mercator
```

Coordinates:

```
EPSG:3857
```


## 6 Why is WebMercator suitable for Internet mapping? {#_6-webmercator-为什么适合互联网地图}

Reason:

1️⃣ Simple calculation
2️⃣ The tile map is well adapted
3️⃣ Easy to convert latitude and longitude

Disadvantages:

```
高纬度地区严重变形
```

# 3\. Map rendering principle (high frequency) {#三、地图渲染原理-高频}

## 7\. What is the principle of tile map (Tile)? {#_7-瓦片地图-tile-原理是什么}

The map is not a whole picture, but:

```
很多小图片
```

Common sizes:

```
256x256
```

URL structure:

```
/z/x/y.png
```

For example:

```
/10/512/345.png
```

Meaning:

```
z = zoom
x = tileX
y = tileY
```


## 8 Why can tiles be infinitely scaled? {#_8-瓦片为什么能无限缩放}

Map usage:

```
金字塔模型
```

Zoom levels:

```
0 → 1 张
1 → 4 张
2 → 16 张
3 → 64 张
```

Formula:

```
tiles = 2^zoom
```

# 5\. Spatial analysis (GIS capabilities) {#五、空间分析-gis能力}

## How to implement 11 Point In Polygon? {#_11-point-in-polygon-怎么实现}

Question:

```
点是否在多边形内
```

Algorithm:

```
射线法
Ray Casting
```

Steps:

```
点向右画一条射线
统计交点数量
```

Rules:

```
奇数 = 内部
偶数 = 外部
```


## 12 How to calculate the distance between two points? {#_12-如何计算两个点距离}

Commonly used:

```
Haversine
```

Because:

```
地球是球体
```

Not simple:

```
√((x1-x2)^2+(y1-y2)^2)
```


## 13 How to find the closest point? {#_13-如何查找最近点}

Commonly used spatial indexes:

```
R-Tree
KD-Tree
```

Avoid:

```
O(n)
```

Optimize to:

```
O(log n)
```
