## 1\. Introduction and positioning {#一、前言与定位}

**Mapbox GL JS** is a high-performance JavaScript map library based on **WebGL** for building **interactive 2D/3D vector map applications**.Unlike traditional maps that use image tiles, Mapbox GL uses **Vector Tiles + GPU rendering** to achieve:

- Live style changes
- Smooth zoom
- 3D architecture
- terrain
- Dynamic data visualization

Therefore in **Data visualization, city digital twin, logistics monitoring, large-screen visualization** Very common in scenarios such as this.


### Comparison of mainstream WebGIS libraries {#主流-webgis-库对比}

| Library | Features | Applicable scenarios |
| ---------------- | --------------------------- | -------------- |
| **Leaflet** | Lightweight, simple, with many plug-ins | Simple map application |
| **OpenLayers** | The most complete GIS function, supporting OGC standards | Professional GIS system |
| **MapLibre GL** | Open source fork of Mapbox v1 | Free vector maps |
| **Mapbox GL JS** | Best visual effects, strong 3D | Business map visualization |
| **Cesium** | Focus on 3D Earth | Digital Earth, Aerospace |

Simple understanding:

- **Leaflet → lightweight map**
- **OpenLayers → GIS Tools**
- **Mapbox → Visual Map**
- **Cesium → 3D Earth**


### Mapbox GL JS v3 capabilities used here {#_2025–2026-mapbox-gl-js-v3-x-新特性}

The CDN examples use version 3.19.0. These are relevant capabilities, not a claim that every feature first appeared in v3; check style and service prerequisites against the matching documentation.

**1）Standard Style**

A new default map style with a more realistic visual representation.

**2) 3D lighting system**

- Realistic shadows of buildings
- Sunshine simulation
- Light angle control

**3）3D Terrain**

Realistic terrain rendering.

**4) New Camera API**

Smoother camera controls.

**5) Performance improvement**

GPU rendering optimization, large-scale data is smoother.

## 3\. Quick overview of core concepts {#三、核心概念速览}

It's important to understand the core structure of Mapbox.


## Map

**Map is a map instance**

```javascript
const map = new mapboxgl.Map({
  container: "map",
  style: "mapbox://styles/mapbox/standard",
});
```


## Camera

Control the map perspective.

```javascript
map.flyTo({
  center: [116.39, 39.9],
  zoom: 12,
  pitch: 60,
});
```


## Style

Map style system.

Follow **Mapbox Style Spec**

```javascript
style: "mapbox://styles/mapbox/satellite-streets-v12";
```


## Sources

data source.

Common types:

```
geojson
vector
raster
raster-dem
```

Example:

```javascript
map.addSource("points", {
  type: "geojson",
  data: "points.geojson",
});
```


## Layers

Layers are used to display data.

Common types:

```
fill
line
circle
symbol
fill-extrusion
```

Example:

```javascript
map.addLayer({
  id: "point-layer",
  type: "circle",
  source: "points",
});
```


## Expressions

Mapbox’s **data-driven styling system**

```javascript
'circle-color':[
'match',
['get','type'],
'restaurant','#ff0000',
'park','#00ff00',
'#0000ff'
]
```


## Controls

Map control:

```
NavigationControl
GeolocateControl
ScaleControl
```

Example:

```javascript
map.addControl(new mapboxgl.NavigationControl());
```


## Popup

Information pop-up window.

```javascript
new mapboxgl.Popup().setLngLat([116, 39]).setHTML("<h3>北京</h3>").addTo(map);
```


## 4\. Make your first cool map in 5 minutes {#四、5-分钟做出第一个炫酷地图}

Complete example:

```html
<div id="map"></div>

<script>
  mapboxgl.accessToken = "TOKEN";

  const map = new mapboxgl.Map({
    container: "map",
    style: "mapbox://styles/mapbox/standard",
    center: [-118.24, 34.05],
    zoom: 10,
    pitch: 60,
    bearing: -20,
  });

  map.addControl(new mapboxgl.NavigationControl());

  map.addControl(
    new mapboxgl.GeolocateControl({
      positionOptions: { enableHighAccuracy: true },
      trackUserLocation: true,
    }),
  );

  map.on("load", () => {
    map.addSource("mapbox-dem", {
      type: "raster-dem",
      url: "mapbox://mapbox.mapbox-terrain-dem-v1",
    });

    map.setTerrain({
      source: "mapbox-dem",
      exaggeration: 1.5,
    });
  });
</script>
```

Effect:

- 3D terrain
- control
- tilt angle

```javascript

  type: "geojson",
  data: "earthquake.geojson",
});

map.addLayer({
  id: "earthquake-layer",
  type: "circle",
  source: "earthquakes",
  paint: {
    "circle-radius": 6,
    "circle-color": "red",
  },
});
```


## 5.3 Data-driven style {#_5-3-数据驱动样式}

```javascript
'circle-radius':[
'interpolate',
['linear'],
['zoom'],
5,2,
15,20
]
```


## 5.4 3D Architecture {#_5-4-3d-建筑}

```javascript
map.addLayer({
  id: "3d-buildings",
  source: "composite",
  "source-layer": "building",
  type: "fill-extrusion",
  paint: {
    "fill-extrusion-height": ["get", "height"],
    "fill-extrusion-color": "#aaa",
  },
});
```


## 5.5 Interaction {#_5-5-交互}

Click event:

```javascript
map.on("click", "poi-layer", (e) => {
  new mapboxgl.Popup().setLngLat(e.lngLat).setHTML("POI").addTo(map);
});
```
