# box model {#盒子模型}

## 1\. What is Box Model? {#一、什么是盒子模型-box-model}

When the browser renders an element, it treats it as a rectangular box.
This box consists of four areas:
<!-- more -->

```
+----------------------------+
|        margin 外边距       |
|  +----------------------+  |
|  |     border 边框      |  |
|  |  +----------------+  |  |
|  |  |  padding 内边距 |  |  |
|  |  | +-------------+ |  |  |
|  |  | | content 内容 | |  |  |
|  |  | +-------------+ |  |  |
|  |  +----------------+  |  |
|  +----------------------+  |
+----------------------------+
```

## 2\. The difference between the two box models (core) {#二、两种盒模型的区别-核心}

| Model type | Calculation method (what width represents) | CSS trigger method |
| -------------- | ----------------------------------------------- | ----------------------------- |
| **Standard Box Model (W3C)** | `width = content` area width, excluding `padding` and `border` | `box-sizing: content-box` (default) |
| **IE box model** | `width = content + padding + border` overall box width | `box-sizing: border-box` |

### Example: {#举例说明}

```css
div {
  width: 200px;
  padding: 10px;
  border: 5px solid;
}
```

| Model | Actual rendering width |
| ----------- | --------------------------------- |
| content-box | 200 + 10 + 10 + 5 + 5 = **230px** |
| border-box | 200 (including padding and border) |

## 3\. Detailed explanation of `box-sizing` attribute {#三、box-sizing-属性详解}

| Attribute value | Meaning |
| ------------- | --------------------------------- |
| `content-box` | width contains only the content area (default) |
| `border-box` | width contains content + padding + border (recommended) |
| `inherit` | Inherit parent element settings |

<iframe class="interactive" frameborder="0" height="390" src="https://interactive-examples.mdn.mozilla.net/pages/css/box-sizing.html" title="MDN Web Docs Interactive Example" width="100%"></iframe>

In the default definition of the [CSS box model](https://developer.mozilla.org/zh-CN/docs/CSS/Box_model), the [`width`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/width) you set for an element is the same as[`height`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/height) will only be applied to the content area of this element.If this element has any [`border`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/border) or [`padding`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/padding) , the width and height of the box when drawn to the screen will be added to the set border and padding values.

Source: <https://developer.mozilla.org/zh-CN/docs/Web/CSS/box-sizing>

## 4\. Practical recommendation writing method (almost all projects are written this way) {#四、实战推荐写法-几乎所有项目都这么写}

Modern front-end projects (Vue/React/Tailwind) will set global settings:

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```

### Advantages: {#优点}

* padding and border no longer affect the total width of the box;
* The layout is more intuitive and reduces calculations;
* Especially suitable for responsive and complex UI (such as cards, forms);

## 5\. Examples and comparisons (perceptual understanding) {#五、举例对比-感性理解}

### 1️⃣Default (content-box) {#_1️⃣-默认情况-content-box}

```html
<div class="box1">content-box</div>
```

```css
.box1 {
  width: 200px;
  padding: 20px;
  border: 10px solid #4f46e5;
  background: #c7d2fe;
}
```

👉 Actual occupied width = 200 + 40 + 20 = **260px**

### 2️⃣ border-box

```html
<div class="box2">border-box</div>
```

```css
.box2 {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 10px solid #4f46e5;
  background: #a5b4fc;
}
```

👉 Actual occupied width = **200px**, better control!

## 6\. Several small traps related to layout {#六、与布局相关的几个小陷阱}

| Scenario | Question |
| ---------------------------- | -------------------------- |
| Set `width: 100%` with padding | Actual width > parent, will overflow (content-box) |
| Want the box to have a fixed size | Using `border-box` is safer |
| Tailwind / ElementPlus default | global `border-box` set |

## 7\. Possible questions from the interviewer {#七、面试官可能的追问}

### ❓1. How to verify the box model? {#❓1-如何验证盒模型}

👉 Open the browser DevTools → Elements → “Computed” panel → Box Model icon to see it at a glance.

### ❓2. Why does CSS Reset need to add `*, *::before, *::after { box-sizing: border-box; }`? {#❓2-为什么-css-reset-要加-before-after-box-sizing-border-box}

👉 Because pseudo elements (`::before`, `::after`) default to content-box, not resetting will affect the layout.

### ❓3. What if you only want some components to use the standard model? {#❓3-如果只想让部分组件使用标准模型}

👉 Partial coverage:

```css
.card {
  box-sizing: content-box;
}
```

## 8\. Interview answer template (30 seconds) {#八、面试答题模板-30秒}

> In CSS, each element is a box, divided into four layers: content, padding, border, and margin.
> The default box model is the standard model (content-box), and width only includes the content area;
> The IE model (border-box) will include both padding and border in width.
> We can control it through the `box-sizing` attribute. Generally, projects will be uniformly set to `border-box`.
> This makes the layout more controllable and avoids width calculation errors, especially in responsive scenarios.

## 9\. Visualization case (recommended to do a demo exercise yourself) {#九、可视化案例-推荐自己做个-demo-练习}

```vue
<template>
  <div class="container">
    <div class="box content-box">content-box</div>
    <div class="box border-box">border-box</div>
  </div>
</template>

<style scoped>
.container {
  display: flex;
  gap: 20px;
}
.box {
  width: 200px;
  padding: 20px;
  border: 10px solid #4f46e5;
  background: #c7d2fe;
  text-align: center;
}
.content-box {
  box-sizing: content-box;
}
.border-box {
  box-sizing: border-box;
  background: #a5b4fc;
}
</style>
```
