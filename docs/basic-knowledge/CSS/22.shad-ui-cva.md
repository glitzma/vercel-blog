## 1\. What is CVA?Understand in one sentence {#一、cva-是什么-一句话理解}

> **CVA = Use "configuration" to describe class combination rules, and use "parameters" to generate className**

It solves only one problem:

> **"Conditional Combination Explosion" of Component Styles**

## 2\. What would happen without a CVA?(pain point) {#二、没有-cva-会发生什么-痛点}

#### ❌ Traditional writing method (unmaintainable) {#❌-传统写法-不可维护}

```tsx
<button
  className={`
    px-4 py-2 rounded
    ${variant === "primary" && "bg-blue-600 text-white"}
    ${variant === "outline" && "border"}
    ${size === "lg" && "h-12 text-lg"}
    ${disabled && "opacity-50"}
  `}
>
```

Question:

* Conditional dispersion
* No type hints
* Add a variant → rewrite a bunch of if

## 3\. CVA’s core API {#三、cva-的核心-api}

```ts
import { cva } from "class-variance-authority"
```

#### minimal model {#最小模型}

```ts
const buttonVariants = cva(
  "base-class",
  {
    variants: {
      variant: {
        primary: "...",
        outline: "...",
      },
      size: {
        sm: "...",
        lg: "...",
      },
    },
  }
)
```

Use:

```ts
buttonVariants({ variant: "primary", size: "lg" })
```

## 4\. Complete Button example (key points) {#四、完整-button-示例-重点}

```ts
const buttonVariants = cva(
  "inline-flex items-center justify-center rounded-md font-medium",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground",
        outline: "border border-input",
        ghost: "hover:bg-accent",
      },
      size: {
        sm: "h-9 px-3",
        md: "h-10 px-4",
        lg: "h-11 px-8",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "md",
    },
  }
)
```

Use:

```tsx
<Button variant="outline" size="lg" />
```

## 5\. Variants / defaultVariants essence {#五、variants-defaultvariants-本质}

#### What are variants? {#variants-是什么}

```ts
variants: {
  size: {
    sm: "h-9",
    lg: "h-11",
  }
}
```

👉 **key is parameter, value is class**

#### What are defaultVariants? {#defaultvariants-是什么}

```ts
defaultVariants: {
  size: "md"
}
```

👉 **Default value when no parameters are passed**

## 6\. Compound conditions: compoundVariants (very important) {#六、复合条件-compoundvariants-很重要}

> Append class when **multiple variants satisfy** at the same time

```ts
compoundVariants: [
  {
    variant: "outline",
    size: "lg",
    class: "uppercase"
  }
]
```

Equivalent to:

```ts
if (variant === "outline" && size === "lg") {
  class += " uppercase"
}
```

## 7\. Boolean variant (commonly used) {#七、布尔型-variant-常用}

```ts
variants: {
  disabled: {
    true: "opacity-50 pointer-events-none",
    false: ""
  }
}
```

Use:

```tsx
<Button disabled />
```

## 8\. CVA + TypeScript (core advantages) {#八、cva-typescript-核心优势}

#### Automatically derive Props types {#自动推导-props-类型}

```ts
import { VariantProps } from "class-variance-authority"

type ButtonVariants = VariantProps<typeof buttonVariants>

interface ButtonProps
  extends React.ButtonHTMLAttributes<HTMLButtonElement>,
    ButtonVariants {}
```

Effect:

```tsx
<Button variant="xxx" /> ❌ TS 报错
<Button size="lg" /> ✅
```

## 9\. className merge (required test) {#九、classname-合并-必考}

```tsx
<button
  className={cn(buttonVariants({ variant, size }), className)}
/>
```

Users can:

```tsx
<Button className="w-full" />
```

## 10\. Design ideas of CVA (very important) {#十、cva-的设计思想-非常重要}

#### 1️⃣ Configure the driver, not the logical driver {#_1️⃣-配置驱动-而不是逻辑驱动}

❌ if / else
✅ declarative config

#### 2️⃣ Style = part of the design system {#_2️⃣-样式-设计系统的一部分}

```ts
variant="destructive"
```

Not:

```ts
bg-red-500
```

#### 3️⃣ The style is "Finite State Machine" {#_3️⃣-样式是-有限状态机}

* variant
* size
* state

## 11\. When should CVA be used? {#十一、什么时候该用-cva}

✅ Used in:

* Button
* Badge
* Alert
* Input
* Tabs Trigger

❌ Not required in:

* Page level layout
* Strong business coupling components
* disposable components

## 12\. Practical combat: write a Badge yourself (step by step) {#十二、实战-自己写一个-badge-一步步}

```ts
const badgeVariants = cva(
  "inline-flex items-center rounded-full px-2 py-1 text-xs",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground",
        success: "bg-green-500 text-white",
        warning: "bg-yellow-500 text-black",
      },
    },
    defaultVariants: {
      variant: "default",
    },
  }
)
```

```tsx
function Badge({ variant }: VariantProps<typeof badgeVariants>) {
  return <span className={badgeVariants({ variant })} />
}
```

## 13\. Common Misunderstandings {#十三、常见误区}

- ❌ Write dozens of utilities in variant
- ❌ Treat business status (loading) as variant
- ❌ Add business judgment to UI components

## 14\. Are you considered “good at CVA”? {#十四、你算-会-cva-了吗}

You can:

* Write out CVA configuration without reading the documentation
* Correctly split variant / size / state
* Use compoundVariants
* Constrain component APIs with TS types
