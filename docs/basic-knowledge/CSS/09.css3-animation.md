# CSS3 animation animation {#css3之animation动画}

**CSS3 `animation` animation** is a more powerful animation mechanism than `transition` in front-end development.
If `transition` is "a simple transition from A to B", then `animation` is "a multi-stage animation that can control the entire process".

Let’s explain it clearly through the system 👇

## 🎬 1. What is `animation`? {#🎬-一、animation-是什么}

> CSS3 `animation` allows defining a series of style changes through **keyframes (`@keyframes`)**,
> The browser will **Automatically calculate in-between frames** , thereby achieving smooth animation.

✅ Simple to understand:
`transition` can only go from **state A → state B**,
And `animation` can define **A → B → C → D...** multi-stage animation.

## 🧩 2. Basic grammar {#🧩-二、基本语法}

### 1️⃣ Define animation (@keyframes) {#_1️⃣-定义动画-keyframes}

```css
@keyframes 动画名称 {
  0%   { /* 起始状态 */ }
  50%  { /* 中间状态 */ }
  100% { /* 结束状态 */ }
}
```

### 2️⃣ Use animation (animation attribute) {#_2️⃣-使用动画-animation-属性}

```css
selector {
  animation: 动画名称 持续时间 速度曲线 延迟 次数 方向 填充模式 播放状态;
}
```

## 🧱 3. Basic Example {#🧱-三、基础示例}

```html
<div class="box"></div>
```

```css
.box {
  width: 100px;
  height: 100px;
  background: #42b983;
  animation: move 2s ease-in-out infinite alternate;
}

@keyframes move {
  from { transform: translateX(0); }
  to { transform: translateX(200px); }
}
```

✅ **Effect:**
The box moves back and forth from side to side, in an eternal cycle.

## 🧠 4. Eight attributes of `animation` {#🧠-四、animation-的八个属性}

| Properties | Function | Example |
| --------------------------- | ----------------------- | -------------------------------------------------------- |
| `animation-name` | Animation name (corresponding to `@keyframes`) | `move` |
| `animation-duration` | duration | `2s`, `500ms` |
| `animation-timing-function` | Speed curve | `ease`, `linear`, `ease-in-out` |
| `animation-delay` | Delay time | `1s` |
| `animation-iteration-count` | Number of plays | `infinite` / `1` / `3` |
| `animation-direction` | Playback direction | `normal` / `reverse` / `alternate` / `alternate-reverse` |
| `animation-fill-mode` | The state after the animation ends | `none` / `forwards` / `backwards` / `both` |
| `animation-play-state` | Control play or pause | `running` / `paused` |

### 🔹 Example: complete writing method {#🔹-示例-完整写法}

```css
.box {
  animation: move 3s linear 1s 2 alternate forwards;
}
```

Equivalent to 👇

```css
.box {
  animation-name: move;
  animation-duration: 3s;
  animation-timing-function: linear;
  animation-delay: 1s;
  animation-iteration-count: 2;
  animation-direction: alternate;
  animation-fill-mode: forwards;
}
```

## 🌀 5. Keyframe definition method {#🌀-五、关键帧定义方式}

### ✅ Percent writing method (recommended) {#✅-百分比写法-推荐}

```css
@keyframes move {
  0% { transform: translateX(0); }
  50% { transform: translateX(150px); background: orange; }
  100% { transform: translateX(300px); background: red; }
}
```

### ✅ from / to abbreviation {#✅-from-to-简写}

```css
@keyframes move {
  from { opacity: 0; }
  to { opacity: 1; }
}
```

## ⚙️ 6. Detailed explanation of animation direction (`animation-direction`) {#⚙️-六、动画方向详解-animation-direction}

| Value | Description | Example |
| ------------------- | --------- | ----------- |
| `normal` | Play forward (default) | 0% → 100% |
| `reverse` | Reverse playback | 100% → 0% |
| `alternate` | forward → reverse alternation | back and forth movement |
| `alternate-reverse` | Reverse → Forward alternation | Back and forth movement (starting from the end point) |

## 🧭 7. Animation end state (`animation-fill-mode`) {#🧭-七、动画结束状态-animation-fill-mode}

| value | description | effect |
| ----------- | ------------------------- | -------------- |
| `none` | Return to the initial state after the animation ends | Default |
| `forwards` | Stay in the end frame state | Often used to maintain the final style after loading is completed |
| `backwards` | Applies initial frame before animation starts | Used in conjunction with `delay` |
| `both` | Apply forwards + backwards at the same time | Valid for both entry and exit |

## 💡 8. Animation control (`animation-play-state`) {#💡-八、动画控制-animation-play-state}

```css
.box:hover {
  animation-play-state: paused; /* 鼠标悬停暂停 */
}
```

## 🎨 9. Multiple animations executed simultaneously {#🎨-九、多个动画同时执行}

```css
animation:
  move 2s linear infinite,
  fade 3s ease-in-out 1s infinite alternate;
```

📌 Separate multiple animations with commas.

## 🧰 10. Common animation cases {#🧰-十、常见动画案例}

### ✅ 1. Fade in/out {#✅-1-淡入淡出-fade-in-out}

```css
@keyframes fade {
  from { opacity: 0; }
  to { opacity: 1; }
}
.fade-in {
  animation: fade 1s ease-in forwards;
}
```

### ✅ 2. Bounce animation (bounce) {#✅-2-弹跳动画-bounce}

```css
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-30px); }
}
.ball {
  animation: bounce 0.6s ease infinite;
}
```

### ✅ 3. Rotate animation (rotate) {#✅-3-旋转动画-rotate}

```css
@keyframes rotate {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}
.spin {
  animation: rotate 1.5s linear infinite;
}
```

## ⚡ 11. Performance optimization suggestions {#⚡-十一、性能优化建议}

| Suggestions | Reasons |
| ------------------------------- | ------------- |
| ✅ Using `transform` and `opacity` animations | Does not trigger layout reflow (high performance) |
| ❌ Avoid animation `width` / `top` / `left` | will trigger layout (slow) |
| ✅ Use `will-change` to optimize in advance | Notify the browser to prepare the animation layer in advance |
| ✅ Control the number of animations | Avoid occupying the GPU for a long time |

Example:

```css
.element {
  will-change: transform, opacity;
}
```

## ⚖️ 12. Comparison and summary with `transition` {#⚖️-十二、与-transition-对比总结}

| Comparison items | `transition` | `animation` |
| ----- | ------------- | ----------- |
| Trigger method | Status change (such as hover) | Can play automatically |
| Controllability | Only start and end can be defined | Multiple keyframes can be defined |
| Repeat play | Not supported | Support loop play |
| Delay and pause | Can be delayed but not paused | Can be delayed, paused, and controlled playback |
| Application scenarios | Simple transition | Complex continuous animation |

### Bezier curve cubic-bezier(x1,y1,x2,y2) {#贝塞尔曲线-cubic-bezier-x1-y1-x2-y2}
By adjusting the Bezier curve, you can set up a variety of animation effects, such as rebound effects. The range of the X-axis is 0~1. The value of the Y-axis is not specified, but it should not be too large.For example: straight line linear, namely cubic-bezier(0,0,1,1)

Bezier curve online tool: <https://cubic-bezier.com/#.17,.67,.83,.67>
