# Summary of frequently asked questions about static pages {#静态页面常见问题汇总}
## Show ellipsis (…) {#显示省略号}
css implements single-line and multi-line text overflow display ellipsis (…)
1\. Single-line text overflow displays ellipses (…)

Ellipses can use text-overflow:ellipsis in IE, but many browsers require a fixed width. At the same time, these browsers do not support the text-overflow:ellipsis setting. Here is a tutorial on displaying ellipses compatible with each browser.Everyone should know that the text-overflow:ellipsis attribute is used to realize the overflow display of ellipsis (...) in a single line of text.Of course, some browsers also need to add the width attribute.

```css
p{
     overflow: hidden;
     white-space: nowrap;
     text-overflow: ellipsis;
 }
 // 一定要设置width
 // 但是这个属性并不支持多行文本溢出显示省略号。
```

2\. Multi-line text overflows and displays ellipses (…)

Page implementation in WebKit browsers or mobile terminals (most browsers with WebKit core) is relatively simple. You can directly use WebKit's CSS extension attribute (WebKit is a private attribute) - webkit-line-clamp; note: This is an unsupported WebKit property, which does not appear in the CSS specification draft.

 -webkit-line-clamp is used to limit the number of lines of text displayed in a block element.In order to achieve this effect, it needs to be combined with other WebKit properties.Common combination attributes:

 display: -webkit-box; must be combined to display the object as a flexible box model.

 -webkit-box-orient must be combined with the attribute to set or retrieve the arrangement of the child elements of the flex box object.

 text-overflow: ellipsis; can be used to hide out-of-range text with ellipsis "..." in the case of multi-line text.

  This attribute is only suitable for WebKit browsers or mobile browsers (mostly WebKit-based browsers)

```css
p{
display: -webkit-box; // 必须结合的属性 ，将对象作为弹性伸缩盒子模型显示 。
-webkit-box-orient; // 必须结合的属性 ，设置或检索伸缩盒对象的子元素的排列方式 。
text-overflow: ellipsis; // 可以用来多行文本的情况下，用省略号“…”隐藏超出范围的文本 。
overflow : hidden;
text-overflow: ellipsis;
display: -webkit-box;
-webkit-line-clamp: 2;
-webkit-box-orient: vertical;
}
```

Browser-compatible solutions
A more reliable and simple method is to set the height of the relatively positioned container and simulate it with elements containing ellipses (…);

```css
p {
    position:relative;
    line-height:1.4em;
    /* 3 times the line-height to show 3 lines */
    height:4.2em;
    overflow:hidden;
}
p::after {
    content:"...";
    font-weight:bold;
    position:absolute;
    bottom:0;
    right:0;
    padding:0 20px 1px 45px;

}
```

Another way

```css
p{position: relative; line-height: 20px; max-height: 40px;overflow: hidden;}
p::after{content: "..."; position: absolute; bottom: 0; right: 0; padding-left: 40px;
background: -webkit-linear-gradient(left, transparent, #fff 55%);
```

In fact, it’s the inline element that’s causing the problem.

> Any visible element that is not a block-level element is an inline element, and its performance characteristics are in the form of "row layout".
—-"The Definitive Guide to CSS"

What this means is that inline elements such as pictures and text are aligned with the baseline of their parent by default. However, what you align is the baseline, and what expands the height is the overall height of the element (bottom line). This will definitely cause a certain gap, which is the problem we had above.The solution can be solved by `vertical-align: top` or `img{display: block;}` or `font-size: 0`.

```
top line
middle line
base line
bottom line
```

- Line height: The vertical distance between the "baseline" of two lines of text
- Leading: The vertical distance from the "bottom line" of one line to the "top line" of the next line
- Half line spacing: vertical distance from "bottom line" to "inline box"
- Half line spacing: (line height - font size)/2
- This example: ·30px= (160px-100px)/2·

The default attribute of vertical-align is baseline. As long as we set an attribute different from baseline, we can avoid this problem.

baseline default.The element is placed on the parent element's baseline.\
sub subscript for vertically aligned text.\
super vertically aligns the text's superscript\
top aligns the top of the element with the top of the tallest element in the row\
text-top aligns the top of the element with the top of the parent element's font\
middle places this element in the middle of the parent element.\
bottom Aligns the top of the element with the top of the lowest element in the row.\
text-bottom aligns the bottom of the element with the bottom of the parent element's font.\
length  
% Arrange this element using the percentage value of the "line-height" attribute.Negative values ​​are allowed.\
inherit specifies that the value of the vertical-align attribute should be inherited from the parent element.

## css font gradient color {#css字体渐变色}

> The focus this time is on two attributes,
> background property
> mask attribute
> These two properties are the key to the two implementation methods respectively.

### Method one {#方式一}

```html
<!DOCTYPE html>
<html>

<head>
    <meta charset="utf-8">
    <style>

    span {
        background: linear-gradient(to right, red, blue);
        -webkit-background-clip: text;
        color: transparent;
    }
    </style>
</head>

<body>
        <span>前端简单说</span>
</body>
</html>
```

[Note] When trying background-clip in chrome, you must bring -webkit-

There is not much code, let’s take a look,\
`background: linear-gradient(to right, red, blue); `
This line sets the background to a gradient color. Please note that this is an abbreviation. In fact, it sets the background-image to a gradient color. No. `background-color ` , is the background image. The value is the gradient color. If you don’t know the gradient color, go here to see it.

Let’s explain below ` background-clip` :
`background-clip` attribute specifies the drawing area of the background

Properties:

```css
border-box:背景被裁剪到边框盒
padding-box:背景被裁剪到内边距框
content-box:背景被裁剪到内容框
```

Due to compatibility issues, not all browsers currently support it.

The value of text means that the text in the block is used as the cropping area to be cropped outward. The background of the text is the background of the block, and the area outside the text will be cropped.

Therefore, we finally write `color: transparent;` to make the text transparent, which means that the background color behind it will be displayed.

### Method 2 {#方式二}

```html
<!doctype html>
<html lang="en">
<head>
<meta charset="UTF-8" />

<style type="text/css">
    h1{
        position: relative;
        color: yellow;
    }
    h1:before{
        content: attr(text);
        position: absolute;
        z-index: 10;
        color:pink;
        -webkit-mask:linear-gradient(to left, red, transparent );
    }
</style>
</head>

<body>
    <h1 text="前端简单说">前端简单说</h1>
</body>

</html>
```

Let’s briefly talk about the code:

The :before selector inserts content before the selected element.\
Use the content attribute to specify the content to be inserted.\
The content value attr is used to obtain the attribute value, content:attr (attribute name);

content: attr(text); can get the text attribute of the element. The text attribute here is a custom attribute. You can also add a tt attribute to the element, like this\
`<h1 tt="前端简单说">前端简单说</h1> `      
Then write the content attribute like this, content: attr(tt); will also work.
