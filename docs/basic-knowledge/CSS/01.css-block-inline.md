# block elements and inline elements in css {#css中的块元素和行内元素}

"**Block-level elements (block)**" and "**Inline elements (inline)**" are one of the basic concepts of CSS layout.
Understanding their differences is very important to master layout (Flex/Grid/Flow).

## 1\. Definition and core differences {#一、定义与核心区别}

| Comparison items | Block-level elements (Block) | Inline elements (Inline) |
| ---------------------- | --------------------------------------- | ----------------------------------- |
| **Expression** | On one line, arranged from top to bottom | Arranged in the same line with other elements |
| **Default Width** | Automatically fills the width of the parent container | Spread by content |
| **Width and height can be set** | ✅ `width` / `height` can be set | ❌ Generally invalid (some exceptions such as `<img>`) |
| **Margin/padding can be set** | ✅ Valid in all directions | ⚠️ Only valid left and right (up and down may not be valid) |
| **Typical tags** | `<div>`, `<p>`, `<section>`, `<header>` | `<span>`, `<a>`, `<em>`, `<strong>` |
| **Line Wrap Features** | Automatic line wrapping | No automatic line wrapping |
| **Formatting Features** | Arrange by block (Block Formatting Context) | Arrange by text flow (Inline Formatting Context) |

## 2\. Example of block-level elements {#二、块级元素示例}

```html
<div>我是块级元素A</div>
<div>我是块级元素B</div>
```

✅ **Effect:**

```
[我是块级元素A]
[我是块级元素B]
```

Each `<div>` is on its own line.

## 3\. Example of inline elements {#三、行内元素示例}

```html
<span>我</span>
<span>是</span>
<span>行内元素</span>
```

✅ **Effect:**

```
我是行内元素
```

All `<span>` will appear side by side on one line.

## 4\. Switchable display types {#四、可切换的显示类型}

The CSS `display` property allows an element to switch between **block level** and **inline**:

| Attribute value | Description |
| ----------------------- | ----------------- |
| `display: block` | Element becomes block level |
| `display: inline` | The element becomes inline |
| `display: inline-block` | ✅ Mixed type: does not occupy an exclusive line, width and height can be set |
| `display: none` | Hidden element |
| `display: flex / grid` | Change to container type (new layout model) |

### 🔸 Example: {#🔸-示例}

```css
span {
  display: block; /* 让行内元素表现为块级 */
}
div {
  display: inline-block; /* 让块元素并排显示 */
}
```

## 5\. `inline-block`: the combination of inline and block {#五、inline-block-行内与块的结合}

`inline-block` element:

* Do not occupy a line;
* You can set `width` and `height`;
* Commonly used for buttons, labels, menu items, etc.

Example:

```html
<span class="btn">按钮A</span>
<span class="btn">按钮B</span>
```

```css
.btn {
  display: inline-block;
  padding: 8px 16px;
  background: #42b983;
  color: #fff;
  border-radius: 4px;
}
```

✅ **Effect:**

> Button A Button B (displayed side by side, and the width and height can be set)

## 6\. Differences between block-level and inline box models {#六、块级与行内盒模型差异}

| Items | Block-level elements | Inline elements |
| ------------------ | ------- | -------------- |
| `width`/`height` | Valid | Not valid (expanded by content) |
| `margin`/`padding` | Valid for top, bottom, left and right | Not fully valid for top and bottom (affected by font) |
| `line-height` | Control the height of the entire line | Control the text spacing |
| `vertical-align` | Invalid | ✅ Valid (control baseline alignment) |

## 7\. Summary of common interview questions {#七、面试常见问题总结}

> Q1️⃣: What is the difference between block-level elements and inline elements?
> Block-level elements occupy one line, can set width and height, and have valid upper and lower margins;
> Inline elements do not wrap, the width and height are determined by the content, and the upper and lower margins are invalid.

> Q2️⃣: How to set the width and height of inline elements?
> Change to `display: inline-block` or `display: block`.

> Q3️⃣: There are gaps between inline elements. Why?
> Because HTML spaces are rendered as text spacing, this can be solved by removing the spaces or setting `font-size: 0`.

> Q4️⃣: Why do block-level elements wrap?
> Because in Normal Flow, block-level boxes are stacked vertically according to the document flow by default.

### BFC layout {#bfc布局}

BFC (Block Formatting Context) is part of the visual CSS rendering of the Web page. It is the area where the layout process of the block box occurs, and it is also the area where floating elements interact with other elements.

1\. BFC is an independent layout environment, and the layout of elements inside BFC does not affect each other from the outside;\
2\. BFC can be triggered by some conditions to achieve layout requirements or solve some problems;\
3\. You can think of BFC as a tool. There is no need to explore its definition, just focus on understanding its functions (characteristics).

#### BFC trigger conditions {#bfc的触发条件}
1\. Root element (`<html>`)\
2、`float值非none    `
3、`overflow值非visible  `
4、`display值为inline-block、table-cell、table-caption、flex、inline-flex    `
5、`position值为absolute、fixed  `

#### Characteristics of BFC {#bfc的特性}

1\. The upper and lower margins of two adjacent containers belonging to the same BFC will overlap (key point)\
2\. When calculating the BFC height, floating elements also participate in the calculation (key point)\
3\. The BFC area will not overlap with the floating container (key point)\
4\. The containers in the BFC are arranged vertically in order\
5\. The margin-left of an element touches the border-left of its containing block.\
6\. BFC is an independent container. Elements inside the container will not affect elements outside the container.

### IFC layout rules {#ifc布局规则}

`Inline Formatting Contexts`, also known as "inline formatting context".

- The child elements are arranged horizontally and horizontally, and the vertical starting point is the top of the element.
- Only horizontal style space will be calculated for child elements. 【 padding、border、margin 】 , the vertical style space will not be calculated, 【 padding、border、margin 】 。
- In the vertical direction, child elements will be aligned in different ways (vertical-align)
- A rectangular area that can completely contain all the boxes on a line is called the line box of the line.The width of the line box is determined by the containing box and the floats within it.
- The "line box" in IFC generally has its left and right sides close to its containing block, but float elements will be arranged first.
- The height of the "line box" in IFC is determined by CSS line height calculation rules. The heights of multiple line boxes under the same IFC may be different.
- When the total width of inline-level boxes is less than the line box containing them, their horizontal rendering rules are determined by the text-align attribute value.
- When an "inline box" exceeds the width of its parent element, it is split into multiple boxes, and these oxes are distributed among multiple "line boxes".If the child element is not forced to wrap, the "inline box" will not be split and will overflow the parent element.

You can also use IFC to do many other things, such as solving vertical centering of elements and inconsistent row heights of multiple text elements.
