## 1\. The main "version stage" of React {#一、react-的主要-版本阶段}

### 1️⃣ React 15 and before (obsolete ❌) {#_1️⃣-react-15-及以前-已过时-❌}

**Features**

* Only supports Class Component
* Complex life cycle (`componentWillMount`, etc.)
* No Hooks

**Conclusion**

> ❌ Not recommended for learning
> Now it is only seen in old projects and is used for "maintenance" rather than "learning".

### 2️⃣ React 16 (an important turning point ⭐) {#_2️⃣-react-16-重要转折点-⭐}

> **The starting point of truly modern React**

**Critical Version**

* **16.0 (2017)**: Fiber Architecture
* **16.8 (2019)**: 🔥 Hooks released (revolutionary)

**New core capabilities**

* `useState`
* `useEffect`
* `useContext`
* `useReducer`
* Functional components become mainstream

**Status**

> 📌 **Must learn the basics** (99% of tutorials start here)

### 3️⃣ React 17 (transitional version 🚧) {#_3️⃣-react-17-过渡版本-🚧}

**Features**

* Few new APIs
* Mainly **upgrade strategy adjustment**
* Event system refactoring (important for library authors)

**Conclusion**

> You can **ignore the sense of existence** when learning and treat it as a continuation of React 16

### 4️⃣ React 18 (current mainstream ⭐⭐⭐) {#_4️⃣-react-18-当前主流-⭐⭐⭐}

> **Learn React Now = Learn React 18**

**Release time**

* 2022

**Core Changes**

#### ✅ Concurrent Features {#✅-并发特性-concurrent-features}

* `createRoot`
* Automatic Batching

#### ✅ New Hooks {#✅-新-hooks}

* `useTransition`
* `useDeferredValue`
* `useId`

#### ✅ Strict mode is more strict {#✅-严格模式更严格}

* Effect will be executed twice under `StrictMode` (development environment)

**Status**

> 📌 **Must master (interview + practical)**

## 2\. React is not a “version”, but a “changing paradigm” {#二、react-不是-版本-而是-范式在变}

When learning React, the more important thing is the following **paradigm upgrade**:

### 🧠 1. Changes in component writing {#🧠-1-组件写法变化}

```jsx
// ❌ 过去（Class）
class App extends React.Component {
  state = { count: 0 }
}

// ✅ 现在（Function + Hooks）
function App() {
  const [count, setCount] = useState(0)
}
```

### 🧠 2. Evolution of status management {#🧠-2-状态管理演进}

* `useState / useReducer`
* `Context`
* Third party:

  * Redux Toolkit (mainstream)
  * Zustand (lightweight)
  * Jotai / Recoil

### 🧠 3. Rendering mode upgrade {#🧠-3-渲染模式升级}

* CSR (traditional)
* SSR（Next.js）
* RSC（React Server Components）

## 3\. The order of study I recommend for you (Important ⭐⭐⭐) {#三、我建议你的学习顺序-重要-⭐⭐⭐}

### 🚀 Phase 1: React 18 Basics (⭐⭐⭐) {#🚀-第一阶段-react-18-基础-⭐⭐⭐}

Must master:

* JSX
* function component
* Hooks：

  * `useState`
  * `useEffect`
  * `useRef`
  * `useMemo`
  * `useCallback`
* Component communication (props/children)

### 🚀 Stage 2: Advanced (⭐⭐⭐) {#🚀-第二阶段-进阶-⭐⭐⭐}

* Custom Hooks
* Context
* Performance optimization (memo/useMemo)
* Controlled/uncontrolled components

### 🚀 The third stage: Ecology (⭐⭐) {#🚀-第三阶段-生态-⭐⭐}

* React Router v6
* State Management (Redux Toolkit/Zustand)
* React Query / TanStack Query

### 🚀 Stage 4: Framework (⭐⭐) {#🚀-第四阶段-框架-⭐⭐}

* Next.js（App Router）
* SSR / SSG / Streaming
