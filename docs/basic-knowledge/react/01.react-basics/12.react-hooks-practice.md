## 1\. Status management practical mode {#一、状态管理实战模式}

### 1️⃣ Local state vs global state split principle {#_1️⃣-局部状态-vs-全局状态拆分原则}

#### ✅ Partial status (priority) {#✅-局部状态-优先}

* form
* Pop-up window switch
* hover / loading
* Local UI state

Use:

```js
useState
useReducer
```

Principles:

> Keep state as close as possible to the component using it

#### ✅ Global status {#✅-全局状态}

Don't abuse Context.

Recommended:

* Lightweight scenario: Context + selector
* Medium and large projects: zustand/jotai
* Super complex: redux-toolkit

Advanced optimization points:

* Cut store (split by domain)
* selector precise subscription
* Avoid top-level large objects

### 2️⃣ useReducer actual combat scenario {#_2️⃣-usereducer-实战场景}

#### Suitable for: {#适合}

* Multi-field linkage form
* State machine process
* Complex business logic

Example:

```js
const [state, dispatch] = useReducer(reducer, initialState)
```

Advantages:

* Centralized status
* testable
* Traceable

Interview highlights:

> Use useReducer to build a lightweight state machine

## 2\. Best practices for side effect management {#二、副作用管理最佳实践}

### 3️⃣ Request encapsulation: useRequest mode {#_3️⃣-请求封装-userequest-模式}

Don't write fetch directly in the component.

#### Recommended structure: {#推荐结构}

```js
function useRequest(service, options) {
  const [data, setData] = useState(null)
  const [loading, setLoading] = useState(false)
  const abortRef = useRef(null)

  const run = useCallback(async (...args) => {
    abortRef.current?.abort()
    const controller = new AbortController()
    abortRef.current = controller

    setLoading(true)
    const result = await service(...args, controller.signal)
    setData(result)
    setLoading(false)
  }, [service])

  useEffect(() => {
    return () => abortRef.current?.abort()
  }, [])

  return { data, loading, run }
}
```

#### Practical points: {#实战点}

* Support cancellation requests
* Support repeated calls
* Prevent memory leaks
* Ensure reference stability

## 4\. Practical solutions to closure problems {#四、闭包问题实战解决方案}

### 7️⃣ Timer Hook package {#_7️⃣-定时器-hook-封装}

Wrong writing:

```js
setInterval(() => console.log(count), 1000)
```

Correct packaging:

```js
function useInterval(callback, delay) {
  const savedCallback = useRef(callback)

  useEffect(() => {
    savedCallback.current = callback
  })

  useEffect(() => {
    const id = setInterval(() => {
      savedCallback.current()
    }, delay)
    return () => clearInterval(id)
  }, [delay])
}
```

Advantages:

* Always get the latest state
* Do not re-register interval

## 6\. Practical combat of concurrency features {#六、并发特性实战}

### 9️⃣ useTransition scenario {#_9️⃣-usetransition-场景}

Search filter:

```js
const [isPending, startTransition] = useTransition()

const onSearch = (value) => {
  setInput(value)

  startTransition(() => {
    setFilteredList(filter(value))
  })
}
```

Effect:

* Input without lag
* filter low priority

### 🔟 useDeferredValue scenario {#🔟-usedeferredvalue-场景}

Used for:

* large table
* Data graph

Differences from useMemo:

* useMemo is cache
* useDeferredValue is the scheduling delay

## 7\. Hooks design specifications (team level) {#七、hooks-设计规范-团队级}

### 1️⃣1️⃣ Custom Hook design principles {#_1️⃣1️⃣-自定义-hook-设计原则}

* Name useXxx
* single responsibility
* Do not expose internal state structures
* The returned object structure is stable

Recommended:

```js
return useMemo(() => ({
  data,
  loading,
  run
}), [data, loading, run])
```

### 1️⃣2️⃣ Dependence on array specification {#_1️⃣2️⃣-依赖数组规范}

Principles:

* Don't ignore ESLint hints
* Don't add eslint-disable casually
* Don't write objects into deps (unless memo)

## 8\. Summary of enterprise-level best practices {#八、企业级最佳实践总结}

### state design {#状态设计}

* state minimized
* Data normalization
* Split granularity

### side effect design {#副作用设计}

* All side effects must be treatable
* Component uninstallation must be considered
* Request must be cancelable

### Performance design {#性能设计}

* Not over-optimized by default
* critical path optimization
* Verify with profiler
