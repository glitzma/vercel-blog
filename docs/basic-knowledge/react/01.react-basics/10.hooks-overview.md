## 1\. Definition of four Hooks {#一、四个-hook-的定义}

| Hook | One sentence function |
| ------------ | -------------------------- |
| `useState` | Manage **component internal mutable state** |
| `useEffect` | Handle **side effects** (things unrelated to React rendering) |
| `useContext` | Cross-level **shared state/dependencies** |
| `useMemo` | Cache **derived calculation results** to avoid repeated calculations |

👉 **They solve completely different problems**

## 2\. Explain clearly one by one (interview level) {#二、逐个讲清楚-面试级}

### 1️⃣ useState - local UI state {#_1️⃣-usestate-——-本地-ui-状态}

#### What is it used for? {#用来干嘛}

* form input
* Is Dialog open?
* Tab switch
* loading (local)

```tsx
const [open, setOpen] = useState(false)
```

#### Features {#特点}

* State change → Component re-renders
* **Only belongs to the current component**

🗣 Interview statement:

> useState manages local component state that affects rendering.

### 2️⃣ useEffect - side effect management {#_2️⃣-useeffect-——-副作用管理}

#### What are side effects? {#什么是副作用}

👉 **Not to blame JSX**

* data request
* Subscribe to events
* DOM manipulation
* Log / Report

```tsx
useEffect(() => {
  fetchUsers()
}, [])
```

#### Key points (foreign companies love to ask) {#关键点-外企爱问}

* **Depends on array to decide when to execute**
* cleanup prevents memory leaks

```tsx
useEffect(() => {
  const id = setInterval(...)
  return () => clearInterval(id)
}, [])
```

🗣 Interview statement:

> useEffect handles side effects outside the render lifecycle.

### 3️⃣ useContext - share data across components {#_3️⃣-usecontext-——-跨组件共享数据}

#### What problem is solved? {#解决什么问题}

> **Avoid props drilling (pass props layer by layer)**

Suitable for:

* current user
* Topic
* Language
* Global configuration

```tsx
const ThemeContext = createContext("light")
```

```tsx
const theme = useContext(ThemeContext)
```

#### Features {#特点-1}

* All consumer components **will re-render**
* Not suitable for high-frequency changing data

🗣 Interview statement:

> useContext provides shared data without prop drilling.

### 4️⃣ useMemo - cache "calculation results" {#_4️⃣-usememo-——-缓存-计算结果}

#### What is it used for? {#用来干嘛-1}

* **Derived Data**
* The computational cost is not low
* Avoid double counting

```tsx
const stats = useMemo(() => compute(users), [users])
```

#### Important differences (common misunderstandings) {#重要区别-常见误区}

* ❌ Not used to "avoid re-render"
* ✅ Only cache **calculation results**

🗣 Interview statement:

> useMemo memoizes expensive derived values.

### The core differences between three and four Hooks (comparison table) {#三、四个-hook-的核心区别-对比表}

| dimensions | useState | useEffect | useContext | useMemo |
| ------- | -------- | --------- | ---------- | ------- |
| Save status | ✅ | ❌ | ❌ | ❌ |
| Whether to trigger rendering | ✅ | ❌ | Indirect | ❌ |
| Whether to deal with side effects | ❌ | ✅ | ❌ | ❌ |
| Whether across components | ❌ | ❌ | ✅ | ❌ |
| Whether performance optimization | ❌ | ❌ | ❌ | ✅ |

📌 **They are not substitutes for each other**

## 4\. All ways to transfer values between components (key points) {#四、组件间传值的所有方式-重点}

### 1️⃣ Father → Son (most common) {#_1️⃣-父-→-子-最常见}

```tsx
<Child name={name} />
```

```tsx
function Child({ name }) {}
```

✅ Most recommended
❌ Not suitable for layers that are too deep

### 2️⃣ child → parent (callback) {#_2️⃣-子-→-父-回调}

```tsx
<Child onSubmit={setValue} />
```

```tsx
function Child({ onSubmit }) {
  onSubmit("data")
}
```

👉Essence: **functions are also props**

### 3️⃣ Brother components (status improvement) {#_3️⃣-兄弟组件-状态提升}

```tsx
<Parent>
  <A />
  <B />
</Parent>
```

👉 Mention state to Parent

### 4️⃣ Across multi-layer components (useContext) {#_4️⃣-跨多层组件-usecontext}

```tsx
<UserContext.Provider value={user}>
  <App />
</UserContext.Provider>
```

```tsx
const user = useContext(UserContext)
```

🗣 Interview statement:

> I use context for cross-cutting concerns like auth or theme.

### 5️⃣ Server status (React Query) {#_5️⃣-服务端状态-react-query}

👉 **Not props, not context**

```tsx
useQuery({ queryKey: ["users"], queryFn })
```

Multiple components share the same server data.

### 6️⃣ State management library (Redux/Zustand) {#_6️⃣-状态管理库-redux-zustand}

Suitable for:

* The status is complex
* Sharing multiple pages
* Frequent updates

## 5\. Combine the real choices of your project (very important) {#五、结合你项目的真实选择-非常重要}

In your project:

| Scene | What to use |
| --------- | ----------- |
| Dialog switch | useState |
| form submission side effects | useMutation |
| Users List | React Query |
| User statistics | useMemo |
| Theme/Login state | useContext |
