## 1\. Overall structure of PostgreSQL type system {#一、postgresql-类型系统整体结构}

PostgreSQL's type system is very rich and allows users to define new data types through `CREATE TYPE`.([PostgreSQL][1])

The official type system is roughly divided into:

```
基础类型（Standard SQL Types）
│
├─ 数值类型
├─ 字符类型
├─ 日期时间
├─ 布尔类型
│
Postgres 特有类型
│
├─ JSON / JSONB
├─ Array
├─ Range / Multirange
├─ Geometric
├─ Network Address
├─ UUID
├─ Full-Text Search
├─ XML
│
复杂类型
│
├─ Composite
├─ Domain
```

One of the design goals of Postgres is to:

> **Make the database not only relational data, but also support multi-model data structures.**


## 2\. Basic data types (Standard SQL Types) {#二、基础数据类型-standard-sql-types}

These types generally conform to the SQL standard.

### 1 Numeric Types {#_1-数值类型-numeric-types}

| Type | Description |
| ---------------- | ----- |
| smallint | 2-byte integer |
| integer | 4-byte integer |
| bigint | 8-byte integer |
| numeric(p,s) | arbitrary precision number |
| real | single precision floating point |
| double precision | double precision floating point |

Example:

```sql
CREATE TABLE products (
  id SERIAL,
  price NUMERIC(10,2),
  stock INTEGER
);
```

Features:

* `numeric` for **financial calculations**
* `float` for **scientific computing**


### 2 auto-increment type {#_2-自增类型}

Postgres provides:

```
serial
smallserial
bigserial
```

Essence:

```
sequence + default
```

For example:

```sql
id SERIAL
```

Equivalent:

```
CREATE SEQUENCE
DEFAULT nextval()
```


### 3 string type {#_3-字符串类型}

| Type | Description |
| ---------- | ---- |
| char(n) | fixed length |
| varchar(n) | variable length |
| text | unlimited length |

Recommended practices:

```
text = varchar
```

Postgres does not limit text performance.


### 4 Binary types {#_4-二进制类型}

```
bytea
```

Used for:

* File
* pictures
* binary data

Example:

```sql
INSERT INTO files(data)
VALUES (decode('FFD8FFE0','hex'));
```


### 5 date and time types {#_5-日期时间类型}

| Type | Description |
| ----------- | ----- |
| date | date |
| time | time |
| timestamp | date time |
| timestamptz | Time with time zone |
| interval | time interval |

Example:

```sql
SELECT now();
```

Recommended:

```
timestamptz
```

Avoid time zone issues.


### 6 Boolean type {#_6-boolean-类型}

```
boolean
```

Value:

```
true
false
null
```

Example:

```sql
SELECT TRUE;
```


## 3\. Postgres unique types (special capabilities) {#三、postgres-特有类型-特色能力}

These types are the key to making Postgres a **multi-model database**.


## 1 JSON / JSONB type {#_1-json-jsonb-类型}

Postgres provides:

```
json
jsonb
```

Difference:

| Type | Features |
| ----- | ------- |
| json | text storage |
| jsonb | Binary parsing storage |

`jsonb`：

* Query faster
* Supports indexes ([PostgreSQL][2])

Example:

```sql
CREATE TABLE users (
  id INT,
  profile JSONB
);
```

Insert:

```sql
INSERT INTO users VALUES
(1,'{"name":"tom","age":20}');
```

Query fields:

```sql
SELECT profile->>'name'
FROM users;
```

JSONB operators:

| Operator | Meaning |
| --- | ------ |
| -> | JSON object |
| ->> | text |
| @> | contains |
| ? | key exists |

Example:

```sql
SELECT *
FROM users
WHERE profile @> '{"age":20}';
```


### jsonpath query {#jsonpath-查询}

Postgres supports SQL/JSON Path:

```sql
SELECT jsonb_path_query(profile,'$.name')
FROM users;
```

Support:

```
wildcard
recursive search
array access
```


## 2 Array type {#_2-array-类型}

Postgres supports array columns.

```sql
CREATE TABLE posts(
  tags TEXT[]
);
```

Insert:

```sql
INSERT INTO posts VALUES
('{react,frontend}');
```

Access elements:

```sql
SELECT tags[1]
FROM posts;
```

Query array:

```sql
SELECT *
FROM posts
WHERE 'react' = ANY(tags);
```

Array search:

```sql
SELECT *
FROM posts
WHERE tags @> ARRAY['react'];
```

Official tip:

Arrays are not collection models.


## 3 Range type {#_3-range-类型}

Unique to Postgres.

means:

```
区间
```

For example:

```
时间段
数值范围
```

Built-in range:

```
int4range
int8range
numrange
tsrange
tstzrange
daterange
```

Example:

```sql
CREATE TABLE booking(
  period TSRANGE
);
```

Insert:

```sql
INSERT INTO booking VALUES
('[2024-01-01,2024-01-10]');
```

Judgment overlap:

```sql
SELECT *
FROM booking
WHERE period && '[2024-01-05,2024-01-07]';
```

Advantages:

```
自动处理区间逻辑
```

## 4\. Advanced query capabilities {#四、高级查询能力}

Postgres query capabilities are very powerful.


## 1 CTE（Common Table Expression）

```
WITH
```

Example:

```sql
WITH recent_orders AS (
  SELECT *
  FROM orders
  WHERE created_at > now() - interval '7 days'
)
SELECT *
FROM recent_orders;
```

Advantages:

```
可读性
模块化SQL
```


## 2 Recursive Query {#_2-递归查询-recursive-query}

Used for:

```
树
图
组织架构
```

Example:

```sql
WITH RECURSIVE tree AS (
  SELECT id,parent_id
  FROM category
  WHERE id=1

  UNION ALL

  SELECT c.id,c.parent_id
  FROM category c
  JOIN tree t ON c.parent_id=t.id
)
SELECT * FROM tree;
```


## 3 Window Functions

Window functions are a strength of Postgres.

Example:

```sql
SELECT
  id,
  salary,
  rank() OVER (ORDER BY salary DESC)
FROM employees;
```

Common:

```
rank()
dense_rank()
row_number()
lag()
lead()
sum() OVER
```


## 4 LATERAL query {#_4-lateral-查询}

LATERAL allows subqueries to reference the previous table.

```sql
SELECT *
FROM users
CROSS JOIN LATERAL
jsonb_each(users.profile);
```

Commonly used for:

```
JSON拆解
数组展开
```


## 5 JSON query {#_5-json-查询}

Postgres JSON queries are very powerful.

Example:

```sql
SELECT *
FROM orders
WHERE data->'customer'->>'name' = 'Tom';
```

Array expansion:

```sql
SELECT jsonb_array_elements(items)
FROM orders;
```


## 6 ARRAY query {#_6-array-查询}

```sql
SELECT unnest(tags)
FROM posts;
```

Expand the array.


## 7 Range Query {#_7-range-查询}

Judgment includes:

```sql

```

Judgment overlap:

```
&&
```
