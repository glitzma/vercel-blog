# 1\. `typeof` (in TS it is "getting the type") {#一、typeof-在-ts-里是-取类型}

⚠️ **TS’s `typeof` ≠ JS’s `typeof`**

| Scenario | JS `typeof` | TS `typeof` |
| ---- | ----------- | ----------- |
| Function | Runtime | Compile time |
| return | string | **type** |

## 1️⃣ Basic usage {#_1️⃣-基本用法}

```ts
const user = {
  id: 1,
  name: "Tom",
  age: 18,
};

type User = typeof user;
```

Equivalent to:

```ts
type User = {
  id: number;
  name: string;
  age: number;
};
```

📌 **Core purpose: Deducing "type" from "value"**

## 2️⃣ Common usage scenarios {#_2️⃣-常见使用场景}

### ✅ Scenario 1: Configuration object → automatic synchronization of types {#✅-场景-1-配置对象-→-类型自动同步}

```ts
const config = {
  mode: "dark",
  size: "small",
};

type Config = typeof config;
```

When you change `config`, the type will change automatically and **will not be out of sync** 👍

### ✅ Scenario 2: Function/hook return value type {#✅-场景-2-函数-hook-返回值类型}

```ts
function useUser() {
  return {
    name: "Tom",
    age: 18,
  };
}

type User = ReturnType<typeof useUser>;
```

(`typeof` + tool type is Wang Zha)

# 2\. `keyof` (get the key of the object) {#二、keyof-取对象的-key}

## 1️⃣ Basic usage {#_1️⃣-基本用法-1}

```ts
type User = {
  id: number;
  name: string;
  age: number;
};

type UserKeys = keyof User;
```

Result:

```ts
type UserKeys = "id" | "name" | "age";
```

📌 **keyof = turn key into a union type**

## 2️⃣The actual value of keyof {#_2️⃣-keyof-的实际价值}

### ✅ Restriction parameters can only be the key of the object {#✅-限制参数只能是对象的-key}

```ts
function getValue<T, K extends keyof T>(obj: T, key: K) {
  return obj[key];
}

getValue(user, "name"); // ✅
getValue(user, "xxx"); // ❌
```

This is one of the core capabilities of TS type safety.

# 3\. `typeof + keyof` (combination punch) {#三、typeof-keyof-组合拳}

## 1️⃣ Get key from "object value" {#_1️⃣-从-对象值-中拿-key}

```ts
const user = {
  id: 1,
  name: "Tom",
  age: 18,
};

type UserKeys = keyof typeof user;
```

Result:

```ts
"id" | "name" | "age";
```

📌 **This is the most common way of writing**

## 2️⃣ Replace enum (strongly recommended for front-end) {#_2️⃣-替代-enum-前端强烈推荐}

```ts
const STATUS = {
  PENDING: "pending",
  SUCCESS: "success",
  ERROR: "error",
} as const;

type Status = (typeof STATUS)[keyof typeof STATUS];
```

Result:

```ts
type Status = "pending" | "success" | "error";
```

💥 Vue / React state management standard writing method

# 4\. Advanced: The importance of `as const` (must understand) {#四、进阶-as-const-的重要性-必懂}

## ❌ No `as const` {#❌-没有-as-const}

```ts
const user = {
  role: "admin",
};

type Role = typeof user.role;
// string ❌
```

## ✅ Use `as const` {#✅-使用-as-const}

```ts
const user = {
  role: "admin",
} as const;

type Role = typeof user.role;
// 'admin' ✅
```

📌 **Conclusion:**

> If you want to get a "literal type", you must use `as const`

# 5\. Common variations of keyof {#五、keyof-的常见变体}

### 1️⃣ `keyof any`

```ts
type Keys = keyof any;
// string | number | symbol
```

### 2️⃣ `keyof` + mapping type {#_2️⃣-keyof-映射类型}

```ts
type ReadonlyObj<T> = {
  readonly [K in keyof T]: T[K];
};
```

This is the underlying principle of `Readonly<T>`.

# 6\. Examples of real front-end scenarios {#六、真实前端场景示例}

## 1️⃣ React props verification {#_1️⃣-react-props-校验}

```ts
const props = {
  size: "small",
  type: "primary",
} as const;

type Props = typeof props;
type PropKeys = keyof Props;
```

## 2️⃣ Vue emit event {#_2️⃣-vue-emit-事件}

```ts
const emits = {
  submit: (value: string) => true,
  cancel: () => true,
};

type EmitName = keyof typeof emits;
// 'submit' | 'cancel'
```

## 3️⃣ Form field constraints {#_3️⃣-表单字段约束}

```ts
type Form = {
  username: string;
  password: string;
};

function updateField(key: keyof Form, value: string) {}
```

# 7\. Summary of common pitfalls (must ask in interviews) {#七、常见坑总结-面试必问}

❌ **keyof is used on values**

```ts
keyof user // ❌
keyof typeof user // ✅
```

❌ **typeof cannot be used on types**

```ts
type A = { a: number };
type B = typeof A; // ❌
```

❌ **forgot as const**

```ts
const arr = ["a", "b"];
type A = (typeof arr)[number]; // string ❌
```

```ts
const arr = ["a", "b"] as const;
type A = (typeof arr)[number]; // 'a' | 'b' ✅
```

# 8\. One sentence memory method 🧠 {#八、一句话记忆法-🧠}

- **typeof: from value → type**
- **keyof: union from type → key**
- **typeof + keyof: union from object → key**
