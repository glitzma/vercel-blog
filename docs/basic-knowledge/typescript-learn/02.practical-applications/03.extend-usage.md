## 1\. Usage 1: Generic constraints (Constraint) {#一、用法-1-泛型约束-constraint}

- **Limit the "value range" of generics**

### 1️⃣ The most basic example {#_1️⃣-最基础示例}

```ts
function getLength<T extends { length: number }>(value: T) {
  return value.length;
}
```

- ✅ string / array
- ❌ number

📌 **extends = T must satisfy a certain structure**

### 2️⃣ Constraint key (UHF) {#_2️⃣-约束-key-超高频}

```ts
function getValue<T, K extends keyof T>(obj: T, key: K) {
  return obj[key];
}
```

Here:

- `K` can only be the key of `T`
- Otherwise, an error will be reported directly

### 3️⃣ Constraint function type {#_3️⃣-约束函数类型}

```ts
type Fn<T extends (...args: any[]) => any> = T;
```

Common writing methods for React/Vue hooks types.

## 2\. Usage 2: Conditional Types {#二、用法-2-条件类型-conditional-types}

- **Return different types like ternary expressions**

### 1️⃣ Basic grammar {#_1️⃣-基本语法}

```ts
T extends U ? X : Y
```

### 2️⃣ Basic example {#_2️⃣-基础示例}

```ts
type IsString<T> = T extends string ? true : false;

type A = IsString<"a">; // true
type B = IsString<123>; // false
```

### 3️⃣ Common built-in tool types {#_3️⃣-常见内置工具类型}

#### `Exclude`

```ts
type MyExclude<T, U> = T extends U ? never : T;
```

#### `Extract`

```ts
type MyExtract<T, U> = T extends U ? T : never;
```

### 4️⃣ Determine function return value (actual combat) {#_4️⃣-判断函数返回值-实战}

```ts
type Return<T> = T extends (...args: any[]) => infer R ? R : never;
```

(This is how `ReturnType` works)

## 3\. Usage 3: Distribution condition type (Distributive) {#三、用法-3-分发条件类型-distributive}

- **Condition type + union type = automatic split calculation**

📌 **This is the most confusing part**

### 1️⃣Look at an example {#_1️⃣-看一个例子}

```ts
type ToArray<T> = T extends any ? T[] : never;

type A = ToArray<string | number>;
```

Calculation process:

```ts
ToArray<string> | ToArray<number>;
// string[] | number[]
```

### 2️⃣ Conditions for distribution to occur (remember this) {#_2️⃣-分发发生的条件-记住这条}

- **Only dispatched if `T` is a "naked type parameter"**

✅ Distribution:

```ts
T extends U ? X : Y
```

❌ Not distributed:

```ts
[T] extends [U] ? X : Y
```

### 3️⃣ Turn off distribution (very important) {#_3️⃣-关闭分发-非常重要}

```ts
type NoDistribute<T> = [T] extends [string] ? true : false;

type A = NoDistribute<string | number>;
// false
```

## 4\. Comparative summary of three usages {#四、三个用法的对比总结}

| Usage | Writing | Occurrence time |
| ---- | --------------------- | -------- |
| Constraints | `<T extends U>` | Generic declaration |
| Condition | `T extends U ? X : Y` | Type calculation |
| Distribution | Condition + Union | Automatic |

## 5\. How to use extends for real tool types? {#五、真实工具类型是怎么用-extends-的}

### 1️⃣ `NonNullable<T>`

```ts
type NonNullable<T> = T extends null | undefined ? never : T;
```

### 2️⃣ `Parameters<T>`

```ts
type Params<T> = T extends (...args: infer P) => any ? P : never;
```

### 3️⃣ `Awaited<T>`

```ts
type Awaited<T> = T extends Promise<infer R> ? Awaited<R> : T;
```

## 6\. Front-end real scene {#六、前端真实场景}

### 1️⃣ Determination of form value type {#_1️⃣-表单值类型判断}

```ts
type FieldValue<T> = T extends HTMLInputElement
  ? string
  : T extends HTMLSelectElement
    ? string
    : never;
```

### 2️⃣ API status type {#_2️⃣-api-状态类型}

```ts
type ApiResult<T> = T extends null
  ? { success: false }
  : { success: true; data: T };
```

## 7\. 3 combos of must-ask questions in the interview (standard answers) {#七、面试必问-3-连击-标准回答}

#### Q1: How many uses of extends in TS? {#q1-extends-在-ts-里有几种用法}

- **3 types: generic constraints/condition types/distribution condition types**

#### Q2: When will distribution occur? {#q2-什么时候会发生分发}

- **When the left side of extends is a naked type parameter and it is a union type**

#### Q3: How to turn off distribution? {#q3-如何关闭分发}

- **Wrap a layer with tuple `[T] extends [U]`**

## 8\. The ultimate memory formula 🧠 {#八、终极记忆口诀-🧠}

- **declaration-time constraint → constraint**
- **Judgment during calculation → condition**
- **United Demolition → Distribution**
