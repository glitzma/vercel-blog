## 1\. What is "mapping type"? {#一、什么是「映射类型」}

One sentence definition:

> **Use an existing type key to batch generate a new type**

Core syntax:

```ts
type NewType<T> = {
  [K in keyof T]: T[K];
};
```

📌 The **`in` here is not the `in`** of JS, but the **type-level traversal key**

## 2\. The most basic example (must know) {#二、最基础示例-一定要会}

### 1️⃣ Handwritten `Readonly<T>` {#_1️⃣-手写-readonly-t}

```ts
type MyReadonly<T> = {
  readonly [K in keyof T]: T[K];
};
```

Equivalent to TS built-in:

```ts
Readonly<T>;
```

### 2️⃣ Handwritten `Partial<T>` {#_2️⃣-手写-partial-t}

```ts
type MyPartial<T> = {
  [K in keyof T]?: T[K];
};
```

### 3️⃣ Handwritten `Required<T>` {#_3️⃣-手写-required-t}

```ts
type MyRequired<T> = {
  [K in keyof T]-?: T[K];
};
```

📌 `-?` means **remove optional modifiers**

## 3\. "Modifiers" in mapping types {#三、映射类型中的「修饰符」}

#### List of modifiers {#修饰符一览}

| Modifier | Meaning |
| ----------- | -------- |
| `readonly` | Read only |
| `?` | Optional |
| `-readonly` | Remove read-only |
| `-?` | Remove optional |

#### Example: remove readonly {#示例-去掉-readonly}

```ts
type Mutable<T> = {
  -readonly [K in keyof T]: T[K];
};
```

## 4\. Mapping + conditional judgment (advanced) {#四、映射-条件判断-进阶}

### 1️⃣ Filter fields based on key (core skills) {#_1️⃣-根据-key-过滤字段-核心技巧}

```ts
type FilterString<T> = {
  [K in keyof T as T[K] extends string ? K : never]: T[K];
};
```

```ts
type User = {
  id: number;
  name: string;
  age: number;
};

type StringProps = FilterString<User>;
// { name: string }
```

📌 **`as` can change the key in the mapping type**

### 2️⃣ key renaming (common in Vue/React source code) {#_2️⃣-key-重命名-vue-react-源码常见}

```ts
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};
```

```ts
type State = {
  count: number;
  name: string;
};
```

Result:

```ts
{
  getCount: () => number;
  getName: () => string;
}
```

## 5\. Essential understanding of `in` (very important) {#五、in-的本质理解-非常重要}

```ts
[K in keyof T]
```

Equivalent to:

```ts
K = "a" | "b" | "c";
```

👉 TS will automatically expand **union types**

```ts
type Keys = "a" | "b";

type Obj = {
  [K in Keys]: number;
};
// { a: number; b: number }
```

## 6\. Real front-end scenario {#六、真实前端场景}

### 1️⃣ Form validation rules {#_1️⃣-表单校验规则}

```ts
type Form = {
  username: string;
  password: string;
};

type Rules<T> = {
  [K in keyof T]: {
    required?: boolean;
    message?: string;
  };
};
```

### 2️⃣ Vue props default value {#_2️⃣-vue-props-默认值}

```ts
type Props = {
  size: string;
  disabled: boolean;
};

type DefaultProps = {
  [K in keyof Props]?: Props[K];
};
```

### 3️⃣ API status mapping {#_3️⃣-api-状态映射}

```ts
type Api = {
  getUser: () => void;
  getList: () => void;
};

type LoadingState<T> = {
  [K in keyof T]: boolean;
};
```

## 7\. Common Misunderstandings (High Frequency Interviews) {#七、常见误区-面试高频}

❌ **`in` can only be used in types**

```ts
[K in arr]; // ❌
```

❌ **Forgot `keyof`**

```ts
[K in T] // ❌
[K in keyof T] // ✅
```

❌ **Think `in` is runtime**

```ts
// 映射类型不会生成 JS 代码
```

## 8\. Mapping type = bottom layer of TS tool type {#八、映射类型-ts-工具类型的底层}

| Tool Type | Bottom |
| ---------- | ------------- |
| `Partial`  | in + ?        |
| `Required` | in + -?       |
| `Readonly` | in + readonly |
| `Pick` | in + condition |
| `Record`   | in            |

## 9\. Memory formula 🧠 {#九、记忆公式-🧠}

- **keyof: get key**
- **in: traverse key**
- **as: change key**
- **extends: sieve key**
