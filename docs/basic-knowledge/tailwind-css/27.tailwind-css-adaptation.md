**"Really adapt Tailwind's design system to H5"**.

## 1\. Three mainstream solutions for H5 adaptation {#一、h5-适配的三种主流方案}

| Solution | Core unit | Is JS required | Is it recommended |
| ----------- | -------- | ------- | ------ |
| rem + JS | rem | ✅ | ⚠️Old solution |
| vw / vh | vw | ❌ | ✅ Mainstream |
| vw + rem hybrid | vw + rem | ❌ | ⭐ enterprise |

📌 **Conclusion (directly to you):**

> 👉 **Tailwind + vw + rem (hybrid) is currently the most stable H5 solution**

## 2\. Why not use pure rem? {#二、为什么不用纯-rem-了}

#### rem problem {#rem-的问题}

* Dependency JS injection
* Shake above the fold
* iframe / webview has pitfalls
* Conflicts with Tailwind default rem

📌 **But rem still has value:**

* Font size
* spacing
* rounded corners

## 3\. Recommended solution structure (key points) {#三、推荐方案架构-重点}

### 👉 Design draft assumptions {#👉-设计稿假设}

* Design width: **375px**

### 👉 Unit Strategy {#👉-单位策略}

| Purpose | Unit |
| ------- | --- |
| layout width and height | vw |
| font | rem |
| spacing / fillet | rem |
| max width | px |

## 4\. Tailwind’s core configuration (key) {#四、tailwind-的核心配置-关键}

### 1️⃣ Set root font-size (no JS required) {#_1️⃣-设置-root-font-size-不需要-js}

```css
/* main.css */
html {
  font-size: 16px;
}
```

### 2️⃣ Modify spacing / fontSize using rem + vw {#_2️⃣-修改-spacing-fontsize-使用-rem-vw}

```js
// tailwind.config.js
export default {
  theme: {
    extend: {
      spacing: {
        // 设计稿 375 → 1vw = 3.75px
        4: '1.067vw',   // 4px
        8: '2.133vw',   // 8px
        12: '3.2vw',
        16: '4.267vw'
      },
      fontSize: {
        sm: '0.875rem',
        base: '1rem',
        lg: '1.125rem'
      }
    }
  }
}
```

📌 **NOTE**

* Do not override default spacing
* only extend what you need

### 5\. A more elegant solution: use clamp (strongly recommended) {#五、更优雅方案-使用-clamp-强烈推荐}

#### core idea {#核心思想}

> Font & Spacing
> **Use vw for small screens, locked for large screens**

#### 1️⃣ clamp font size {#_1️⃣-clamp-字号}

```js
fontSize: {
  base: 'clamp(14px, 3.7vw, 16px)',
  lg: 'clamp(16px, 4vw, 18px)'
}
```

#### 2️⃣ clamp spacing {#_2️⃣-clamp-间距}

```js
spacing: {
  4: 'clamp(4px, 1.067vw, 8px)',
  8: 'clamp(8px, 2.133vw, 16px)'
}
```

📌 **This is the default solution for H5 from major manufacturers**

## 6\. vw layout class (plug-in method, the cleanest) {#六、vw-布局类-插件方式-最干净}

### Write a vw tool plug-in {#写一个-vw-工具类插件}

```js
// plugins/vw.js
import plugin from 'tailwindcss/plugin'

export default plugin(({ addUtilities }) => {
  addUtilities({
    '.vw-full': { width: '100vw' },
    '.vh-full': { height: '100vh' },
    '.vw-safe': {
      paddingLeft: 'env(safe-area-inset-left)',
      paddingRight: 'env(safe-area-inset-right)'
    }
  })
})
```

## 7\. Practical examples of Vue/H5 pages {#七、vue-h5-页面实战示例}

```vue
<template>
  <div class="vw-full min-h-screen bg-gray-50">
    <header class="p-4 text-lg font-bold">
      标题
    </header>

    <section class="px-4 space-y-4">
      <div class="p-4 bg-white rounded-xl shadow-card">
        内容卡片
      </div>
    </section>
  </div>
</template>
```

📌 Features:

* The layout automatically changes with the screen
* The font is not blown up
* iPad / horizontal screen controllable

## 8\. Maximum width limit (very important) {#八、最大宽度限制-非常重要}

```html
<div class="max-w-[480px] mx-auto"></div>
```

📌 Prevent iPad/large screen H5 from losing control

## 9\. Common pitfalls & underlying explanations {#九、常见坑-底层解释}

#### 1️⃣ vw becomes larger in horizontal screen {#_1️⃣-vw-在横屏变大}

✅ Solution:

```css
@media (orientation: landscape) {
  html {
    font-size: 14px;
  }
}
```

#### 2️⃣ Does Tailwind’s default rem conflict with vw? {#_2️⃣-tailwind-默认-rem-和-vw-冲突}

Will not:

* Tailwind just generates CSS
* Units are completely defined by you

#### 3️⃣ Why not use PostCSS px → vw? {#_3️⃣-为什么不用-postcss-px-→-vw}

❌ Will affect third-party components
❌ debug difficult

📌 Tailwind itself is a design system and does not require secondary conversion.

## 10\. Complete recommended configuration template (you can use it directly) {#十、完整推荐配置模板-你可直接用}

```js
export default {
  content: ['./index.html', './src/**/*.{vue,js,ts}'],
  theme: {
    extend: {
      fontSize: {
        base: 'clamp(14px, 3.7vw, 16px)',
        lg: 'clamp(16px, 4vw, 18px)'
      },
      spacing: {
        4: 'clamp(4px, 1.067vw, 8px)',
        8: 'clamp(8px, 2.133vw, 16px)',
        12: 'clamp(12px, 3.2vw, 24px)'
      }
    }
  }
}
```
