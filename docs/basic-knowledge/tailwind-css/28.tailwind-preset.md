**H5 Tailwind preset** is essentially the **vw / rem / clamp / safe-area / design token**
👉 **Packaged into a "pluggable design system module"**.

## 1\. What is Tailwind preset? {#一、什么是-tailwind-preset}

> **preset = "configuration modularity" of tailwind.config**

```txt
项目
 ├─ tailwind.config.js
 └─ presets/
     └─ h5.js   👈 你要做的
```

preset can contain:

* theme(color/spacing/font)
* plugins（vw / safe-area / utilities）
* darkMode / screens
* even safelist

📌 **Ideal for:**

* Multiple H5 projects
* Middle and backend + H5 shared design system
* Component Library/Infrastructure

## 2\. Design goals of H5 preset (very critical) {#二、h5-preset-的设计目标-很关键}

Our preset needs to be solved:

- 1️⃣ **375 design draft automatic adaptation**
- 2️⃣ **vw does layout, rem does stability**
- 3️⃣ **clamp control limit**
- 4️⃣ **Safe Area (Notch)**
- 5️⃣ **Does not rely on JS (SSR/WebView friendly)**

## 3\. Directory structure (recommended) {#三、目录结构-推荐}

```txt
h5-tailwind-preset/
├─ index.js
├─ theme.js
├─ plugins/
│  ├─ vw.js
│  └─ safe-area.js
└─ README.md
```

## 4\. Core preset implementation {#四、核心-preset-实现}
### 1️⃣ theme.js (design token) {#_1️⃣-theme-js-设计-token}

```js
// theme.js
export const theme = {
  extend: {
    fontSize: {
      xs: 'clamp(12px, 3.2vw, 14px)',
      sm: 'clamp(14px, 3.7vw, 16px)',
      base: 'clamp(16px, 4vw, 18px)',
      lg: 'clamp(18px, 4.5vw, 20px)'
    },

    spacing: {
      2: 'clamp(4px, 1.067vw, 8px)',
      4: 'clamp(8px, 2.133vw, 16px)',
      6: 'clamp(12px, 3.2vw, 24px)',
      8: 'clamp(16px, 4.267vw, 32px)'
    },

    borderRadius: {
      md: '8px',
      lg: '12px',
      xl: '16px'
    },

    boxShadow: {
      card: '0 4px 12px rgba(0,0,0,.08)'
    }
  }
}
```

📌 **Instructions**

* spacing / fontSize using clamp
* Do not override Tailwind defaults
* Keep rem/px controllable

### 2️⃣ vw tool plug-in {#_2️⃣-vw-工具插件}

```js
// plugins/vw.js
import plugin from 'tailwindcss/plugin'

export default plugin(({ addUtilities }) => {
  addUtilities({
    '.vw-full': { width: '100vw' },
    '.vh-full': { height: '100vh' },
    '.min-vh-full': { minHeight: '100vh' }
  })
})
```

### 3️⃣ safe-area plug-in (required for H5) {#_3️⃣-safe-area-插件-h5-必备}

```js
// plugins/safe-area.js
import plugin from 'tailwindcss/plugin'

export default plugin(({ addUtilities }) => {
  addUtilities({
    '.safe-px': {
      paddingLeft: 'env(safe-area-inset-left)',
      paddingRight: 'env(safe-area-inset-right)'
    },
    '.safe-pt': {
      paddingTop: 'env(safe-area-inset-top)'
    },
    '.safe-pb': {
      paddingBottom: 'env(safe-area-inset-bottom)'
    }
  })
})
```

### 4️⃣ preset main entrance {#_4️⃣-preset-主入口}

```js
// index.js
import { theme } from './theme'
import vw from './plugins/vw'
import safeArea from './plugins/safe-area'

export default {
  darkMode: 'class',

  theme,

  plugins: [
    vw,
    safeArea
  ]
}
```

## 5\. How to use it in projects (key points) {#五、在项目中如何使用-重点}
### tailwind.config.js

```js
import h5Preset from './presets/h5'

export default {
  content: ['./index.html', './src/**/*.{vue,js,ts}'],
  presets: [h5Preset]
}
```

📌 **NOTE**

* presets is an array
* Multiple presets can be superimposed

## 7\. Extension methods of preset (advanced but very practical) {#七、preset-的扩展方式-高级但很实用}
### 1️⃣ Allow users to override the width of the design draft {#_1️⃣-允许用户覆盖设计稿宽度}

```js
// index.js（高级）
export default function h5Preset(options = {}) {
  const designWidth = options.designWidth || 375

  const vw = (px) => `${(px / designWidth) * 100}vw`

  return {
    theme: {
      extend: {
        spacing: {
          4: `clamp(8px, ${vw(8)}, 16px)`
        }
      }
    }
  }
}
```

Use:

```js
presets: [
  h5Preset({ designWidth: 390 })
]
```

📌 **This step = Enterprise Level**

## 8\. Why is preset more advanced than "copy config"? {#八、为什么-preset-比-复制-config-高级}

| Method | Question |
| --------- | ----------- |
| Copy config | Not upgradeable |
| npm package | Highly intrusive |
| preset | ⭐ Can be combined / can be overridden |

📌 **preset is the reuse method officially recommended by Tailwind**
