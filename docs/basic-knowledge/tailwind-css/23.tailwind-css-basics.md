## 1\. What is Tailwind (core idea) {#一、tailwind-是什么-核心思想}

> **Utility First (Atomic CSS)**

* No (or very little) traditional CSS written
* Use **class name to directly describe the style**
* Class name = style semantics, not business semantics

```html
<button class="px-4 py-2 bg-blue-500 text-white rounded">
  Button
</button>
```

Equivalent to:

```css
button {
  padding: 8px 16px;
  background: #3b82f6;
  color: #fff;
  border-radius: 6px;
}
```

## 2\. Core basic classification {#二、核心基础分类}

### 1️⃣ Layout {#_1️⃣-布局-layout}

#### display

```html
<div class="block"></div>
<div class="inline-block"></div>
<div class="flex"></div>
<div class="grid"></div>
```

#### Flex (extremely common) {#flex-极其常用}

```html
<div class="flex items-center justify-between">
```

* `flex-row / flex-col`
* `items-center` (cross-axis)
* `justify-center / between / around` (spindle)

#### Grid

```html
<div class="grid grid-cols-3 gap-4">
```

### 2️⃣ Spacing {#_2️⃣-间距-spacing}

#### margin / padding

```html
<div class="m-4 p-2"></div>
<div class="mt-4 mb-2"></div>
<div class="px-4 py-2"></div>
```

> Memory method:

* `m / p`
* `t r b l x y`
* Number = `4px * n`

### 3️⃣Size {#_3️⃣-尺寸-size}

```html
<div class="w-32 h-16"></div>
<div class="w-full h-screen"></div>
<div class="max-w-md"></div>
```

Commonly used:

* `w-full`
* `h-screen`
* `min-h-screen`
* `max-w-xl`

### 4️⃣Typography {#_4️⃣-文字-typography}

```html
<p class="text-sm text-gray-600"></p>
<p class="text-lg font-bold"></p>
<p class="leading-relaxed tracking-wide"></p>
```

* `text-xs ~ text-2xl`
* `font-light / normal / medium / bold`
* `text-left / center / right`

### 5️⃣ Color {#_5️⃣-颜色-color}

```html
<div class="bg-red-500 text-white"></div>
<div class="border border-gray-200"></div>
```

Structural unity:

```
{property}-{color}-{level}
```

Such as:

* `bg-blue-500`
* `text-gray-700`
* `border-zinc-200`

### 6️⃣ Borders & Rounded Corners & Shadow {#_6️⃣-边框-圆角-阴影}

```html
<div class="border rounded-lg shadow-md"></div>
```

* `rounded / rounded-md / rounded-full`
* `shadow / shadow-lg`

### 7️⃣ Position {#_7️⃣-定位-position}

```html
<div class="relative">
  <span class="absolute top-0 right-0"></span>
</div>
```

* `relative`
* `absolute`
* `fixed`
* `sticky`

## 3\. Responsive (Tailwind is very strong) {#三、响应式-tailwind-很强}

### breakpoint prefix {#断点前缀}

```txt
sm   ≥640px
md   ≥768px
lg   ≥1024px
xl   ≥1280px
2xl  ≥1536px
```

### Usage {#用法}

```html
<div class="text-sm md:text-base lg:text-lg"></div>
```

📌 **Mobile first**

## 4\. Status modification (very important) {#四、状态修饰-非常重要}

### hover / focus / active

```html
<button class="bg-blue-500 hover:bg-blue-600 focus:ring-2">
```

### group (father-son linkage) {#group-父子联动}

```html
<div class="group">
  <span class="group-hover:text-red-500"></span>
</div>
```

## 5\. Dark Mode {#五、暗黑模式-dark-mode}

```html
<div class="bg-white dark:bg-gray-900 text-black dark:text-white">
```

`tailwind.config.js`：

```js
darkMode: 'class'
```

## 6\. Common combination routines (actual combat) {#六、常见组合套路-实战}

### ✅ Cards {#✅-卡片}

```html
<div class="p-4 rounded-lg shadow bg-white">
```

### ✅ Centered {#✅-居中}

```html
<div class="flex items-center justify-center h-screen">
```

### ✅ Button {#✅-按钮}

```html
<button
  class="px-4 py-2 bg-blue-500 text-white rounded hover:bg-blue-600 transition"
>
```

## 7\. Key points for using Tailwind in Vue {#七、tailwind-在-vue-中的使用要点}

### 1️⃣ dynamic class {#_1️⃣-动态-class}

```vue
<div :class="isActive ? 'bg-blue-500' : 'bg-gray-300'"></div>
```

or:

```vue
<div :class="['p-4', isActive && 'bg-blue-500']"></div>
```

### 2️⃣ Avoid purging dynamic classes {#_2️⃣-避免-purge-掉动态类}

❌

```js
`bg-${color}-500`
```

✅

```js
const map = {
  red: 'bg-red-500',
  blue: 'bg-blue-500'
}
```

## 8\. When not to use Tailwind? {#八、什么时候不用-tailwind}

❌

* Super complex animation (recommended to cooperate with CSS / GSAP)
* Lots of repetitive components but no abstraction
* Collaboration with designers who are extremely sensitive to classes

✅

* Backstage/Midstage
* Component library
* rapid prototyping
* H5 page

## 9\. Study sequence suggestions (for you) {#九、学习顺序建议-给你}

1. **Spacing / Flex / Typography**
2. **Responsive + Status Modification**
3. **Dark Mode**
4. **Tailwind Config（theme / extend）**
5. **Component abstraction (@apply / componentization)**
