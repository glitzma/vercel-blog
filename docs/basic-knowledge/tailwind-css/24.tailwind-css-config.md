「 **When should you change config and when shouldn't you?** 」。

## 1\. What is tailwind.config.js for? {#一、tailwind-config-js-是干嘛的}

In one sentence:

> **Design System (Design Token) Configuration Center**

You define here:

* color system
* spacing / font size / rounded corners
* breakpoint
* animation
* dark mode
* plug-in

```js
// tailwind.config.js
export default {
  content: ['./index.html', './src/**/*.{vue,js,ts,jsx,tsx}'],
  theme: { },
  plugins: []
}
```

## 2\. theme vs extend (key points) {#二、theme-vs-extend-重点}

### 1️⃣ theme: **Completely override the default value** {#_1️⃣-theme-完全覆盖默认值}

❌ Not recommended for novices

```js
theme: {
  colors: {
    primary: '#1677ff'
  }
}
```

⚠️ Consequences:
👉 **Default red / blue / gray are all gone**

### 2️⃣ extend: **Extend on the default basis (99% use this)** {#_2️⃣-extend-在默认基础上扩展-99-用这个}

✅ Correct posture

```js
theme: {
  extend: {
    colors: {
      primary: '#1677ff'
    }
  }
}
```

📌 **Conclusion**

> 👉 Business projects: **Always use extend first**

## 3\. The most commonly used extend item {#三、最常用的-extend-项}

### 1️⃣ Colors {#_1️⃣-颜色-colors}

#### Define dominant/semantic colors {#定义主色-语义色}

```js
extend: {
  colors: {
    primary: '#1677ff',
    success: '#52c41a',
    warning: '#faad14',
    danger: '#ff4d4f'
  }
}
```

Use:

```html
<div class="bg-primary text-white"></div>
```

#### Define a complete set of color levels (recommended) {#定义一整套色阶-推荐}

```js
colors: {
  primary: {
    50:  '#e6f4ff',
    100: '#bae0ff',
    500: '#1677ff',
    700: '#0958d9'
  }
}
```

```html
<div class="bg-primary-500 hover:bg-primary-700"></div>
```

📌 **This is like a design system**

### 2️⃣ Font size (fontSize) {#_2️⃣-字号-fontsize}

```js
extend: {
  fontSize: {
    xs: ['12px', '16px'],
    sm: ['14px', '20px'],
    base: ['16px', '24px'],
    lg: ['18px', '28px']
  }
}
```

Structure:

```js
fontSize: [fontSize, lineHeight]
```

### 3️⃣ Spacing {#_3️⃣-间距-spacing}

```js
extend: {
  spacing: {
    18: '72px',
    22: '88px'
  }
}
```

```html
<div class="mt-18 px-22"></div>
```

📌 Commonly used in **irregular design drafts**

### 4️⃣ Rounded corners (borderRadius) {#_4️⃣-圆角-borderradius}

```js
extend: {
  borderRadius: {
    xl: '12px',
    '2xl': '16px'
  }
}
```

### 5️⃣ Shadow (boxShadow) {#_5️⃣-阴影-boxshadow}

```js
extend: {
  boxShadow: {
    card: '0 4px 12px rgba(0,0,0,.08)',
    popup: '0 8px 24px rgba(0,0,0,.12)'
  }
}
```

```html
<div class="shadow-card"></div>
```

### 6️⃣ Breakpoints (screens) {#_6️⃣-断点-screens}

```js
extend: {
  screens: {
    xs: '480px',
    '3xl': '1600px'
  }
}
```

```html
<div class="xs:text-sm 3xl:text-xl"></div>
```

## 4\. Dark mode configuration (commonly used) {#四、暗黑模式配置-常用}

```js
export default {
  darkMode: 'class'
}
```

Use:

```html
<div class="bg-white dark:bg-gray-900"></div>
```

Vue switch:

```js
document.documentElement.classList.toggle('dark')
```

## 5\. Animation & keyframes (advanced but commonly used) {#五、动画-keyframes-进阶但常用}

### Define animation {#定义动画}

```js
extend: {
  keyframes: {
    fadeIn: {
      '0%': { opacity: 0 },
      '100%': { opacity: 1 }
    }
  },
  animation: {
    fade: 'fadeIn .3s ease-out'
  }
}
```

```html
<div class="animate-fade"></div>
```

## 6\. Abstract style: @apply (cautious) {#六、抽象样式-apply-谨慎}

```css
/* main.css */
.btn {
  @apply px-4 py-2 rounded bg-primary text-white hover:bg-primary-700;
}
```

📌 **Principles of use**

* Component Library/Public Components ✅
* Page private style ❌ (direct class)

## 7\. Pitfalls in cooperation with Vue / Vite {#七、和-vue-vite-配合的坑点}

### 1️⃣ content must be complete {#_1️⃣-content-一定要全}

```js
content: [
  './index.html',
  './src/**/*.{vue,js,ts}'
]
```

### 2️⃣ Dynamic classes will be purged away {#_2️⃣-动态-class-会被-purge-掉}

❌

```vue
<div :class="`bg-${color}-500`" />
```

✅

```js
const colorMap = {
  primary: 'bg-primary-500',
  danger: 'bg-danger-500'
}
```

## 8\. Recommend a set 【 Enterprise-level config template 】 {#八、推荐一套【企业级-config-模板】}

```js
export default {
  darkMode: 'class',
  content: ['./index.html', './src/**/*.{vue,js,ts}'],
  theme: {
    extend: {
      colors: {
        primary: {
          50: '#e6f4ff',
          500: '#1677ff',
          700: '#0958d9'
        }
      },
      boxShadow: {
        card: '0 4px 12px rgba(0,0,0,.08)'
      },
      borderRadius: {
        xl: '12px'
      }
    }
  }
}
```

## 9\. When should I change the config? {#九、什么时候该改-config}

✅ **Should be changed**

* The design draft has clear main color / rounded corners / shadow specifications
* Want to unify the style
* Make component library/middle and backend

❌ **should not be changed**

* Just a special style for a certain page
* One-time demo
* Pure pilot project
