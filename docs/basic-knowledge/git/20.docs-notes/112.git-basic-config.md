### ssh key configuration {#ssh-key-配置}

1\. Generate SSH Key

1\. Check whether the .ssh folder exists

```bash
$ ls -al ~/.ssh
```

2\. If the new .ssh file does not exist, create a new .ssh file.

```bash
$ mkdir ~/.ssh
```

3\. Generate the KEY and enter it in the command line. Replace your_email@example.com with your own email.

```bash
$ cd ~/.ssh

$ ssh-keygen -t rsa -C "your_email@example.com"
```

The system prompts you to enter the file storage location and other information. Just press Enter three times in succession. The saving path of the generated SSH key file will be given in the terminal: id_rsa id_rsa.pub

4\. View the public key

```bash
$ cat id_rsa.pub
```
5\. Copy the public key to the clipboard

```bash
$ pbcopy <id_rsa.pub 
```

### git server prohibits user shell login {#git服务器禁止用户shell登录}

(1) Reasons for prohibition

In order to develop team projects, we often use distributed version management systems, of which git is the most important and commonly used distributed management system today.
The famous gitHub is a website that provides hosting services based on the git system for various people with content hosting needs. However, GitHub's free service can only create public warehouses.If we don't want to open source our code and want to keep it private, then setting up a git server is also a good choice.
After establishing the git server, everyone can pass

```bash
$ git clone git@10.3.0.99:project.git
```

Clone the code locally.
This also shows that everyone can also pass

```bash
$ ssh git@10.3.0.99
```

SSH connects to the server, logs in to the server, and performs various operations on the server. This is usually unsafe and inappropriate. Members only need to be able to operate the warehouse and do not need greater permissions.

(2) Prohibition method

Editing the /etc/passwd file is completed.Find a line similar to the following:

```bash
git:x:1001:1001:,,,:/home/git:/bin/bash
改为：
git:x:1001:1001:,,,:/home/git:/usr/bin/git-shell
```

In this way, Git users can use git through ssh normally, but cannot log in to the shell, because the git-shell we specified for the git user automatically logs out every time they log in.

### Git pushes a project to multiple remote repositories simultaneously {#git-将一个项目同时推送到多个远程仓库}
1. Solution

Check the status of the remote warehouse,

```bash
git remote -v

```
The output is as follows. You can see that there is only one remote warehouse called origin.

```bash
origin  git@github.com:xxx/xxx-ai.git (fetch)
origin  git@github.com:xxx/xxx-ai.git (push)
```

Use the following command to add a remote repository.(Create an empty library in advance)

```bash
git remote set-url --add origin git@192.168.31.111:xxx/xxx-ai.git
```

Check the status of remote warehouse,

```bash
git remote -v
```

You can see that the origin remote warehouse has two push addresses.

```bash
origin  git@github.com:xxx/xxx-ai.git (fetch)
origin  git@github.com:xxx/xxx-ai.git (push)
origin  git@192.168.31.111:xxx/xxx-ai.git (push)

```

##### Method one {#方法一}

git config --global alias.fix '!f() { git commit -m "($(git config user.project))[$(git config user.name)]fix($(git config user.projectCn)|$(date +%Y%m%d)):$1"; }; f' # 修复bug

##### Method two {#方法二}

Configuration via shell script

```bash
#!/bin/bash
# 定义用户信息

USER_NAME=$(git config user.name)
USER_PROJECT=$(git config user.project)
USER_PROJECTCN=$(git config user.projectCn)

# 定义数组
aliases = ("fix", "feat", "docs", "Style", "refactor", "chore", "revert", "pref", "test", "improvement", "build", "ci", "update")

# 循环遍历数组并配置别名

for alias in "${aliases[@]}"; do
    git config --global alias."$alias" '!f() { git commit -m "($(USER_PROJECT))[$(USER_NAME)]$(alias)($(USER_PROJECTCN)|$(date +%Y%m%d));$1"; }; f'
done

echo "Git aliases with user information have been set."

```

run script

1. Save the script as setup_git_aliases_with_user.sh
2. Make sure you have configured Git user information (git config user.name and git config user.project and git config user.projectCn)
3. Add execution permissions to the script

```bash
chmod +x setup_git_aliases_with_user.sh
```

1. run script

```bash
./setup_git_aliases_with_user.sh
```
