代码面向 Vite 5/6 插件 API，演示自动导入而非完整复刻 unplugin-auto-import；自动类型声明、非 Vue 模板和复杂打包链需另行集成验证。

 **从 0 实现“自动导入 API”功能的 Vite 插件**，核心思想与 **unplugin-auto-import** 一样。

## 🎯 最终效果示例（插件做到什么） {#🎯-最终效果示例-插件做到什么}

例如你在 Vue 或 React 项目里写代码：

```ts
const state = ref(0)
watch(state, () => {})
onMounted(() => {})
```

即使你没有写：

```ts
import { ref, watch, onMounted } from 'vue'
```

插件也会在编译阶段自动帮你加上。

最终编译变成：

```ts
import { ref, watch, onMounted } from 'vue'

const state = ref(0)
watch(state, () => {})
onMounted(() => {})
```

## 🧠 插件核心原理 {#🧠-插件核心原理}

Vite 的 `transform()` hook 能拿到文件源码：

```
transform(code, id)
```

我们做三件事：

### ① 扫描代码：找出哪些 API 被使用 {#_1-扫描代码-找出哪些-api-被使用}

例如 ref / computed / watch 等

### ② 判断这些 API 来自哪个库（vue/react/vueuse 等） {#_2-判断这些-api-来自哪个库-vue-react-vueuse-等}

### ③ 自动生成 import 语句 + prepend 在文件最前面 {#_3-自动生成-import-语句-prepend-在文件最前面}

## 🚀 Step 1：创建插件文件 {#🚀-step-1-创建插件文件}

创建 `plugins/auto-import.js`

## 🚀 Step 2：写一个最简自动导入插件 {#🚀-step-2-写一个最简自动导入插件}

下面的核心示例用 AST 和作用域识别自由变量，避免重复导入。需安装 @babel/parser、@babel/traverse 和 magic-string；Vue SFC 由 @vitejs/plugin-vue 先编译，插件使用 post 顺序处理生成的 JavaScript。

```js
import { parse } from '@babel/parser'
import traverseModule from '@babel/traverse'
import MagicString from 'magic-string'

const traverse = traverseModule.default || traverseModule

export default function autoImport(options = {}) {
  const imports = options.imports || {
    vue: ['ref', 'reactive', 'computed', 'watch', 'onMounted']
  }
  const sourceByName = new Map()
  for (const [pkg, names] of Object.entries(imports)) {
    for (const name of names) {
      if (sourceByName.has(name) && sourceByName.get(name) !== pkg) {
        throw new Error('Ambiguous auto-import: ' + name)
      }
      sourceByName.set(name, pkg)
    }
  }

  return {
    name: 'vite-plugin-auto-import',
    enforce: 'post',
    transform(code, id) {
      const filename = id.split('?')[0]
      if (id.includes('node_modules') ||
          !/\.(js|jsx|ts|tsx|vue)$/.test(filename) ||
          /[?&]type=style(?:&|$)/.test(id)) return
      const ast = parse(code, {
        sourceType: 'module',
        plugins: filename.endsWith('.ts') ? ['typescript'] : ['typescript', 'jsx']
      })
      const used = new Map()
      traverse(ast, {
        ReferencedIdentifier(p) {
          const name = p.node.name
          if (!sourceByName.has(name) || p.scope.hasBinding(name)) return
          const pkg = sourceByName.get(name)
          if (!used.has(pkg)) used.set(pkg, new Set())
          used.get(pkg).add(name)
        }
      })
      if (!used.size) return
      const statements = [...used].map(([pkg, names]) =>
        'import { ' + [...names].join(', ') + ' } from ' + JSON.stringify(pkg) + ';'
      )
      const result = new MagicString(code)
      result.prepend(statements.join('\n') + '\n')
      return {
        code: result.toString(),
        map: result.generateMap({ source: id, hires: true, includeContent: true })
      }
    }
  }
}
```

## 🚀 Step 3：在 Vite 中使用插件 {#🚀-step-3-在-vite-中使用插件}

`vite.config.js`：

```js
import vue from '@vitejs/plugin-vue'
import AutoImport from './plugins/auto-import.js'

export default {
  plugins: [
    vue(),
    AutoImport({
      imports: {
        vue: ['ref', 'reactive', 'computed', 'watch', 'onMounted'],
        'vue-router': ['useRoute', 'useRouter']
      }
    })
  ]
}
```

## 🧠 Step 4：处理 Vue SFC（只编译 `<script>` 内容） {#🧠-step-4-处理-vue-sfc-只编译-script-内容}

不要用正则抽出 script 后丢弃整个 SFC 的 template/style。上例通过 post 顺序接收 Vue 插件编译后的模块，并保留模块的查询参数处理。

```js
const filename = id.split('?')[0]
// 对编译后的 JS 做作用域分析，不能把原始 SFC 当作普通 JS 解析
```

## 🧠 Step 5：避免重复导入（真正专业） {#🧠-step-5-避免重复导入-真正专业}

如果用户已经手动写了：

```ts
import { ref } from 'vue'
```

我们要避免重复添加。

必须检查当前引用是否已有词法绑定，而不是只检测文件里是否出现 import。核心实现的判断如下：

```js
if (sourceByName.has(name) && !p.scope.hasBinding(name)) {
  // 当前引用没有局部声明或导入绑定时，才加入候选导入
}
```

已有导入、别名和局部同名变量由作用域分析处理；注释、字符串与非引用属性名不会作为自由变量导入。

## 🧠 Step 6：通过 AST 提升精确度 {#🧠-step-6-通过-ast-提升精确度}

使用 @babel/parser 解析抽象语法树：

```bash
npm i -D @babel/parser@7 @babel/traverse@7 magic-string@0.30
```

示例：

```js
import { parse } from '@babel/parser'
import traverseModule from '@babel/traverse'
const traverse = traverseModule.default || traverseModule
const ast = parse(code, { sourceType: 'module', plugins: ['typescript', 'jsx'] })
```

然后检测：

```js
const usedApis = new Set()
traverse(ast, {
  ReferencedIdentifier(p) {
    if (!p.scope.hasBinding(p.node.name)) usedApis.add(p.node.name)
  }
})
```

这样就不会误判字符串内容。

## 🧠 Step 7：构建完整插件 {#🧠-step-7-构建完整插件}

以下是可继续扩展的目录结构；自动类型声明等能力尚未在上面的核心代码中实现：

```
auto-import/
 ├─ index.js
 ├─ utils/scan.js
 ├─ utils/generate.js
 ├─ package.json
```

核心 index.js 会负责：

* 读取用户配置
* 分析源码
* 使用 AST 找 used identifiers
* 自动生成 import
* 支持 Vue 文件
* 支持多包映射
* 后续可增加 dts（自动生成声明文件）

如：

```ts
// auto-import.d.ts
declare const ref: typeof import('vue')['ref']
```

你完全可以继续扩展。
