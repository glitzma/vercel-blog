本文的 JavaScript 配置和插件片段以 Tailwind CSS 3 为基准。Tailwind CSS 4 使用 CSS 优先配置，兼容旧配置时需用 `@config` 显式加载，不能直接假定旧配置会自动生效。[升级说明](https://tailwindcss.com/docs/upgrade-guide)。

**「把 Tailwind 的设计系统，真正落地到 H5 适配」**。

## 一、H5 适配的三种主流方案 {#一、h5-适配的三种主流方案}

| 方案          | 核心单位     | 是否需要 JS | 是否推荐   |
| ----------- | -------- | ------- | ------ |
| rem + JS    | rem      | ✅       | ⚠️ 老方案 |
| vw / vh     | vw       | ❌       | ✅ 主流   |
| vw + rem 混合 | vw + rem | ❌       | ⭐ 企业级  |

📌 **结论（直接给你）：**

> 👉 **本文演示 Tailwind + vw + rem 的组合，实际单位策略取决于设计与可访问性需求。**

## 二、使用 rem 时需要区分什么？ {#二、为什么不用纯-rem-了}

#### rem 的问题 {#rem-的问题}

* rem 本身不依赖 JS；只有特定的动态根字号方案才需要 JS
* JS 延后修改根字号可能引起首屏位移
* iframe 使用自身文档的根字号，WebView 还需验证缩放设置
* 修改根字号会同时改变 Tailwind 默认 rem 工具类的尺寸

📌 **但 rem 仍然有价值：**

* 字号
* 间距
* 圆角

## 三、推荐方案架构（重点） {#三、推荐方案架构-重点}

### 👉 设计稿假设 {#👉-设计稿假设}

* 设计宽度：**375px**

### 👉 单位策略 {#👉-单位策略}

| 用途      | 单位  |
| ------- | --- |
| 布局宽高    | vw  |
| 字体      | rem |
| 间距 / 圆角 | rem |
| 最大宽度    | px  |

## 四、Tailwind 的核心配置（关键） {#四、tailwind-的核心配置-关键}

### 1️⃣ 设置 root font-size（不需要 JS） {#_1️⃣-设置-root-font-size-不需要-js}

```css
/* main.css */
html {
  font-size: 16px;
}
```

### 2️⃣ 修改 spacing / fontSize 使用 rem + vw {#_2️⃣-修改-spacing-fontsize-使用-rem-vw}

```js
// tailwind.config.js
export default {
  theme: {
    extend: {
      spacing: {
        // 设计稿 375 → 1vw = 3.75px
        'h5-4': '1.067vw',   // 4px
        'h5-8': '2.133vw',   // 8px
        'h5-12': '3.2vw',
        'h5-16': '4.267vw'
      },
      fontSize: {
        sm: '0.875rem',
        base: '1rem',
        lg: '1.125rem'
      }
    }
  }
}
```

📌 **注意**

* H5 spacing 使用独立的 h5-* 名称，保留默认 spacing；fontSize 示例则有意调整已有字号
* 只 extend 你需要的

### 五、更优雅方案：使用 clamp（强烈推荐） {#五、更优雅方案-使用-clamp-强烈推荐}

#### 核心思想 {#核心思想}

> 字体 & 间距
> **小屏用 vw，大屏锁死**

#### 1️⃣ clamp 字号 {#_1️⃣-clamp-字号}

```js
fontSize: {
  base: 'clamp(14px, 3.7vw, 16px)',
  lg: 'clamp(16px, 4vw, 18px)'
}
```

#### 2️⃣ clamp 间距 {#_2️⃣-clamp-间距}

```js
spacing: {
  'h5-4': 'clamp(4px, 1.067vw, 8px)',
  'h5-8': 'clamp(8px, 2.133vw, 16px)'
}
```

📌 **clamp 可约束视口单位的上下限，仍需验证缩放和横屏效果。**

## 六、vw 布局类（插件方式，最干净） {#六、vw-布局类-插件方式-最干净}

### 写一个 vw 工具类插件 {#写一个-vw-工具类插件}

```js
// plugins/vw.js
import plugin from 'tailwindcss/plugin'

export default plugin(({ addUtilities }) => {
  addUtilities({
    '.vw-full': { width: '100vw' },
    '.vh-full': { height: '100vh' },
    '.vw-safe': {
      paddingLeft: 'env(safe-area-inset-left)',
      paddingRight: 'env(safe-area-inset-right)'
    }
  })
})
```

## 七、Vue / H5 页面实战示例 {#七、vue-h5-页面实战示例}

```vue
<template>
  <div class="vw-full min-h-screen bg-gray-50">
    <header class="p-h5-4 text-lg font-bold">
      标题
    </header>

    <section class="px-h5-4 space-y-h5-4">
      <div class="p-h5-4 bg-white rounded-xl shadow-md">
        内容卡片
      </div>
    </section>
  </div>
</template>
```

📌 特点：

* 布局自动随屏幕变化
* 字体不炸
* iPad / 横屏可控

## 八、最大宽度限制（非常重要） {#八、最大宽度限制-非常重要}

```html
<div class="max-w-[480px] mx-auto"></div>
```

📌 max-width 只限制容器，内部 vw 仍按整个视口计算；可配合 clamp，或按需求改用容器单位。

## 九、常见坑 & 底层解释 {#九、常见坑-底层解释}

#### 1️⃣ vw 在横屏变大 {#_1️⃣-vw-在横屏变大}

✅ 解决：

```css
.h5-spacing {
  padding: clamp(4px, 1.067vw, 8px);
}
```

#### 2️⃣ Tailwind 默认 rem 和 vw 冲突？ {#_2️⃣-tailwind-默认-rem-和-vw-冲突}

不会：

* Tailwind 只是生成 CSS
* 单位完全由你定义

#### 3️⃣ 为什么不用 PostCSS px → vw？ {#_3️⃣-为什么不用-postcss-px-→-vw}

❌ 会影响第三方组件
❌ debug 困难

📌 Tailwind 本身就是设计系统，不需要二次转换

## 十、完整推荐配置模板（你可直接用） {#十、完整推荐配置模板-你可直接用}

```js
import vw from './plugins/vw.js'

export default {
  content: ['./index.html', './src/**/*.{vue,js,ts}'],
  plugins: [vw],
  theme: {
    extend: {
      fontSize: {
        base: 'clamp(14px, 3.7vw, 16px)',
        lg: 'clamp(16px, 4vw, 18px)'
      },
      spacing: {
        'h5-4': 'clamp(4px, 1.067vw, 8px)',
        'h5-8': 'clamp(8px, 2.133vw, 16px)',
        'h5-12': 'clamp(12px, 3.2vw, 24px)'
      }
    }
  }
}
```
