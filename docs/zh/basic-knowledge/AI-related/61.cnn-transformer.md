> 从 CNN → RNN → Transformer → BERT → GPT
> 把“大模型的发展逻辑”完整讲清楚。

下面按教学顺序比较几类架构；它们有交叉与并行发展，不是一条严格的历史先后或替代链。


## 一、从 CNN 理解局部特征 {#一、最早阶段-cnn-卷积神经网络}

### 代表论文：ImageNet Classification with Deep Convolutional Neural Networks {#代表论文-imagenet-classification-with-deep-convolutional-neural-networks}

作者：Alex Krizhevsky 等


### 1️⃣ CNN 是干什么的？ {#_1️⃣-cnn-是干什么的}

CNN 主要用于：

> 图像识别

例如：

* 识别猫狗
* 人脸识别
* 医学影像分析


### 2️⃣ 核心思想 {#_2️⃣-核心思想}

CNN 的关键是：

> 卷积（Convolution）

简单理解：

* 用一个“小窗口”在图像上滑动
* 提取局部特征
* 一层层组合成更高级特征

比如：

* 第一层识别边缘
* 第二层识别形状
* 第三层识别物体


### 3️⃣ CNN 处理语言时的取舍 {#_3️⃣-为什么-cnn-不适合做语言}

CNN 不限于二维图像，一维卷积也能处理语言序列。局部卷积的感受野有限，可通过堆叠、扩张卷积等方式扩大；不能由“语言是序列”推出 CNN 无法建模语言。

例如 [Convolutional Sequence to Sequence Learning](https://arxiv.org/abs/1705.03122) 使用卷积进行序列建模。这里比较的是依赖建模与计算方式的取舍。

## 二、序列时代：RNN（循环神经网络） {#二、序列时代-rnn-循环神经网络}


### 1️⃣ RNN 解决什么问题？ {#_1️⃣-rnn-解决什么问题}

RNN 解决：

> 语言是时间序列

它可以“记住前面的话”。

比如：

“我今天没带伞，因为____”

RNN 会记住“没带伞”。


### 2️⃣ RNN 的核心机制 {#_2️⃣-rnn-的核心机制}

每一步：

```
当前输入 + 上一步的记忆 → 当前状态
```

它像一个“会传递记忆的网络”。


### 3️⃣ 但 RNN 有两个严重问题 {#_3️⃣-但-rnn-有两个严重问题}

#### ❌ 1. 记忆会衰减（梯度消失） {#❌-1-记忆会衰减-梯度消失}

句子太长就记不住。

#### ❌ 2. 时间步之间存在顺序依赖 {#❌-2-不能并行计算}

传统 RNN 的时间步依赖前一状态，但批次和其它维度仍可并行。

训练非常慢。


后来出现改进：

* LSTM
* GRU

LSTM/GRU 缓解了部分长期依赖问题，但仍有顺序计算和优化成本，不能说它们完全没有改善。


## 三、革命：Transformer {#三、革命-transformer}

### 代表论文：Attention Is All You Need {#代表论文-attention-is-all-you-need}

作者来自：Google


这篇论文改变了一切。


### 1️⃣ Transformer 解决了什么？ {#_1️⃣-transformer-解决了什么}

两个核心突破：

#### ✅ 不再使用 RNN {#✅-不再使用-rnn}

#### ✅ 使用 Attention 机制 {#✅-使用-attention-机制}


### 2️⃣ 什么是 Attention？ {#_2️⃣-什么是-attention}

一句话：

> self-attention 在允许的注意力掩码内关联 token；双向编码器可看前后文，因果解码器不能看未来位置。

例如：

“我今天没带伞，因为天气很好”

“没带伞”会关注“天气很好”。

这就是：

> 远距离依赖建模


### 3️⃣ Transformer 的优势 {#_3️⃣-transformer-的优势}

| 特性    | RNN | Transformer |
| ----- | --- | ----------- |
| 长距离依赖 | 差   | 强           |
| 并行计算 | 时间步存在顺序依赖 | 训练可并行处理位置；自回归生成仍逐步进行 |
| 训练速度  | 慢   | 快           |
| 扩展性   | 弱   | 极强          |

Transformer 成为大模型基础。


## 四、BERT：双向理解模型 {#四、bert-双向理解模型}

### 代表论文：BERT: Pre-training of Deep Bidirectional Transformers {#代表论文-bert-pre-training-of-deep-bidirectional-transformers}


### 1️⃣ BERT 是什么？ {#_1️⃣-bert-是什么}

BERT 是：

> 基于 Transformer 的“理解型模型”

它是：

> Encoder-only 模型


### 2️⃣ 什么叫双向？ {#_2️⃣-什么叫双向}

GPT 只能从左往右读：

> 我 今天 很 …

BERT 是双向：

> 同时看左边和右边

比如：

“苹果很好吃”

BERT 会根据上下文判断“苹果”是水果还是公司。


### 3️⃣ BERT 擅长什么？ {#_3️⃣-bert-擅长什么}

* 文本分类
* 情感分析
* 搜索排序
* 问答系统

但：

❌ 不擅长生成文章


## 五、GPT：生成模型的崛起 {#五、gpt-生成模型的崛起}

### GPT 代表系列： {#gpt-代表系列}

* GPT-3
* GPT-4
  来自：OpenAI


### 1️⃣ GPT 是什么？ {#_1️⃣-gpt-是什么}

GPT 是：

> 基于 Transformer Decoder 的生成模型

它是：

> 自回归模型（Auto-regressive）

意思是：

> 一个词一个词往后预测


### 2️⃣ GPT 和 BERT 的区别 {#_2️⃣-gpt-和-bert-的区别}

| 对比   | BERT    | GPT     |
| ---- | ------- | ------- |
| 结构   | Encoder | Decoder |
| 是否双向 | 是       | 否       |
| 擅长   | 理解      | 生成      |
| 典型任务 | 分类      | 写作      |


### 3️⃣ 为什么 GPT 可以成为“大模型”？ {#_3️⃣-为什么-gpt-可以成为-大模型}

三个原因：

#### 1️⃣ 可扩展性极强 {#_1️⃣-可扩展性极强}

模型规模因具体架构而异；不能把未公开的参数数量当作已知事实：

* 小规模模型可以只有数亿参数
* GPT-3 论文公开的最大版本为 1750 亿参数
* 其它模型需区分总参数与激活参数，并引用公开报告

#### 2️⃣ 预训练 + 微调 {#_2️⃣-预训练-微调}

先学通用语言
再做人类对齐

#### 3️⃣ Scaling Law

在特定数据、训练预算和评估条件下，扩大规模可能改善表现，并非参数越多就必然在所有任务上更好。


## 六、从 CNN 到 GPT 的进化逻辑 {#六、从-cnn-到-gpt-的进化逻辑}

下面是用途概览，不表示技术按此顺序出现或只能完成表中任务：

```
CNN → 图像理解
RNN → 序列建模
Transformer → 全局注意力
BERT → 强理解
GPT → 强生成
```

本质变化是：

从“特定任务模型”
到“通用语言模型”


## 七、现在的大模型本质是什么？ {#七、现在的大模型本质是什么}

现代大模型 =

```
Transformer架构
+ 海量数据预训练
+ 超大参数规模
+ 人类反馈对齐
```

它不是简单的“聊天机器人”。

它是：

> 语言空间中的通用推理引擎。


## 八、用一句话总结每个阶段 {#八、用一句话总结每个阶段}

CNN：

> 学会看图

RNN：

> 学会记忆序列

Transformer：

> 学会全局理解

BERT：

> 学会深度理解文本

GPT：

> 学会生成世界
