# 第 09 课：关键词搜索与语义搜索 {#lesson-09}

同一条续借规定，有人问“能续借多久”，有人问“还书日期能往后推吗”。前一句容易直接找到“续借”，后一句可能没有任何原词重合。搜索方式不同，结果就可能不同。

## 关键词先抓住写出来的东西 {#keyword}

关键词搜索关注词语出现的情况。实际系统会分词、处理表达并排序，并不是只能找完全一样的句子。书名、订单号、文件编号、日期这些信息，保留原词往往很有用。

问“二〇二六年十月十八日是否开放”，这个日期不能丢。只剩“是否开放”，就很容易找回普通开放时间 A，却漏掉当天的 D。问题里的精确信息，也是检查答案适不适用的线索。

## 语义搜索帮你换一种说法 {#semantic}

语义搜索尝试比较含义，常用向量表示找到候选。“往后推”可能与续借联系起来，让你不必猜中原文用词。但“借期十四天”和“续借七天”也很相近，仍需要看哪段回答了真正的问题。

关键词可能漏同义表达，语义可能找到主题对、条件错的段落。哪种更适合，得拿具体问题试。想知道历史上限时，E 就是需要的资料；问当前上限时，E 又可能带来混淆。

## 改写时，别把问题改丢了 {#rewrite}

“归还日期能往后推几天”可以改成“续借延长多久”，两句都在问延长时间。改成“借期多久”就偏了。改写后回头看对象、时间、否定和条件，比一味追求更多命中更重要。

有些问题同时需要两种信号：日期要精确，口语要理解。后面会讲怎样合并两类候选。这一篇先分别观察，免得同时改变太多东西，看不出谁帮上了忙。

试写四道题，两个用资料原词，两个换一种说法。为每题写预期片段，再试着手动找。记录哪道需要改写，以及改写有没有改变原意。

::: details 两组可对照的问法

“续借延长多久”与“还书日期能往后推几天”都找 C。“当前最多几本”找 B，“二〇二五年最多几本”找 E。后两题只差一个时间条件，预期证据就不同。

:::
