# 第 11 课：怎样提出适合知识库回答的问题 {#lesson-11}

“明天还能借吗？”如果你是图书管理员，恐怕也要先问一句：想知道明天开不开馆，还是某本书能不能借？知识库助手遇到的也是这个问题。找到再多带“借”字的段落，都未必回答了你真正想问的事。

## 哪个信息缺了，会改变答案 {#clarification}

提问不用写得像填表，但对象、时间和条件里，影响答案的部分要说清。“借多久”是在问首次借期，还是续借延长？“多借一点”是数量，还是多留几天？这几个词一换，B 和 C 就可能用反了。

“明天”还依赖今天是哪一天。本练习只有约定现在是二〇二六年十月十七日，明天才是十八日；没有约定，就不能替用户套上特殊闭馆日期。实际问答中，可以利用已明确的上下文，也可以简短追问。

有些信息不用追问，比如问题已经明确问普通图书的借期。把每个简单问题都盘问一遍，会让人觉得难用。判断标准是：缺的这一项，会不会让答案不同？

## 问清楚了，资料也未必能回答 {#scope}

“讨论室一次最多用多久”可以查 G。“现在还有空房吗”就需要实时余量。资料包只有使用规则，问得再清楚，也不能从规则推出现在哪间房空着。遇到这类问题，要换数据来源。

所以不要把每次答不上来都归咎于用户不会问。你要分别检查问题是否明确，以及知识库有没有所需事实。

## 一个问题里，可能藏着两次查询 {#decomposition}

“十八日能进去借三本书吗”既问开馆，又问借阅数量。B 支持三本，D 却说当天闭馆。只找到数量规则就回答“可以”，把决定能否去的条件漏了。

可以先拆成“当天开吗”和“上限几本”，找齐资料后再回答整个问题。拆题是为了不遗漏，不是把两句答案并排放上去就结束。

今天写五道题：数量、续借的口语问法、某个具体日期、证件与数量组合、押金。给每题写预期片段。再把一个模糊问题改写清楚，回头检查对象、时间和条件有没有被你改掉。

::: details 对照一下预期资料

数量找 B，续借找 C，十八日找 D，证件与数量找 F、B，押金目前没有依据。“书能多留几天”要先确认是否在问续借，不能直接改成首次借期。

:::
