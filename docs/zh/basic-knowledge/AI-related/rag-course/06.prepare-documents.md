# 第 06 课：怎样准备一份适合问答的资料 {#lesson-06}

先别急着把文件塞进知识库。你收集了一份手册、几张公告截图和一段聊天记录，看起来很齐全，里面却可能混着旧规则、漏掉的字和没有出处的转述。后面的模型再认真，也可能照着这些资料答错。

准备资料的第一件事，是把“这份东西能不能作为依据”弄清楚。

## 从问题倒推需要什么资料 {#coverage}

图书馆助手要回答借几本、借多久、周末几点关门，就需要对应规则。活动新闻再多，也不能替代借阅说明。先写几道常见问题，给每题找一份能回答的来源，比单纯追求文件数量更有用。

找不到来源的题先留空。例如资料包没有罚金和押金说明，这就是待补的内容。留空会让你看到知识库的边界，随手填一个常见金额则会把猜测变成“资料”。

## 数字和“不”字值得多看一眼 {#extraction}

图片、PDF 和表格经常需要先提取文字。提取完成后别只看有没有正文，回原文核对数字、单位和否定词。“十四天”变“四十天”容易发现，“不可外借”少了一个“不”，却可能藏在一段顺畅文字里。表格还要检查一条规定有没有串到别的行。

这个阶段手动录入短文完全可以。我们需要的是可信文字，暂时不用为八张资料卡搭建一套自动解析程序。

## 把日期和状态跟着正文留下来 {#versions}

B 与 E 都讲借书数量：一个三本，一个两本。只拷正文，会得到两条矛盾规则；留下标题、日期以及 E 已被替代的说明，就能知道哪条用于当前问题，哪条用于历史比较。

这类附加信息叫元数据，metadata。先记录标题、出处、发布或生效时间、适用范围和状态就够了。有些文件发布后才生效，两种日期不一定相同。旧文件可以保留，但归档标记也要一起保留。

拿 A 至 H 做一份资料清单，或者选三到五份公开短文。每份写一句“它能回答什么”，再核对五处数字或条件。最后列出两个仍无法回答的问题。做完，你会比只看到一堆文件更清楚下一步该整理什么。

::: details 清单里可以看到这些区别

B 是当前借阅规则，E 是归档规则，D 只说明指定日期的闭馆。没有收费说明，就暂时不能回答罚金或押金。也不要把两本、三本合成“两到三本”：原文没有这种弹性范围。

:::
