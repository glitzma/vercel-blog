# 第 14 课：资料不足或互相矛盾时怎么办 {#lesson-14}

两份规则，一个说两本，一个说三本。遇到这种答案不一致的资料，先别急着让模型“选最新的”。看清楚它们分别在说哪个时间、哪种情况，往往比选一个数字更重要。

## B 与 E，其实在回答不同年份 {#versions}

资料包已经说明，E 是二〇二五年归档版，被二〇二六年规则替代。问当前上限，用 B 的三本；问去年与今年有什么变化，E 的两本也要留下来。把旧资料一律删掉，反而没法回答历史问题。

这里能作选择，是因为替代关系有明文。现实文件只显示一个较新日期，还不够证明它替代了旧制度：可能是草稿、另一分馆的规则，或者只改了一个无关章节。

## A 与 D，一个是平常，一个是例外 {#scope}

A 说周日开放，D 说十八日全天闭馆。这两句可以同时成立：A 是普通时段，D 指定了一天的特殊安排。回答十八日时用 D；比较平常与那天，就把两条分别说明。

也别把例外扩展成所有周日闭馆，或十九日仍闭馆。资料写多大范围，结论就用多大范围。

## 如果真的判断不了，就把冲突摆出来 {#unresolved}

另外做两张练习卡：X 写“现行借期十四天”，Y 写“现行借期二十一天”，都没有日期、发布部门和替代说明。这两张不属于 A 至 H，只用来练习冲突。现在你没有足够信息决定谁有效。

合适的回答是说明两份资料不同，需要核对有效版本。不能取平均数，也不能因为十四天更熟悉就选它。排名、文字长度、模型的肯定语气，都不能补上缺失的权威信息。

押金题则没有冲突，只有空缺。说“这些资料无法确定押金要求”即可。可以建议核对收费说明，但不要把建议写成已经查过的结果。问题里其他能回答的部分，仍然可以回答。

试着给 B/E、A/D、X/Y 各写一句回答，再给押金写一句。四句的确定程度应当不同：前两组能解释差异，第三组缺有效性信息，最后一题缺事实。

::: details 看看有没有越过资料的范围

当前三本、历史两本有依据；特殊日期闭馆、普通周日开放也有依据。X/Y 不能擅自选一条。押金未知不等于没有押金。关键是把能确定的理由写出来。

:::
