I believe everyone uses search engines frequently, but sometimes when you want to search for a certain piece of information, you find a lot of irrelevant ones (Baidu: What are you looking at me for?).Below we will introduce several search techniques that can improve search efficiency and help you quickly look up information.


## Tip 1: Eliminate distractions {#技巧1-排除干扰项}
**way** : Keyword 1+space+minus sign+keyword 2, that is `关键词1 -关键词2`

**Function**: Exclude some unwanted keywords

**Example**:
```
锤子 -锤子手机
```
An example of excluding search results with `锤子手机` Related, show only `锤子` The way it is.
> After testing on Baidu search, some keywords can be excluded, but some are not easy to use.


## Tip 2: Precise search {#技巧2-精确搜索}
**way** : Add double quotes to keywords, `"关键词"`

**Function**: Only search for words in quotation marks, even if one word is missing or the word is split, it will not work

**Example**:
```
"达拉不崩吧"
```
> Note the double quotes in English

## Tip 3: Search within a specified website {#技巧3-指定网站内搜索}
**way** ： `site:域名 关键词`

**Function**: Search only the content of the specified domain name

**Example**:
```
site:zhihu.com 前端
```
Some of the built-in searches on some sites are not easy to use. You can try this search technique.

## Tip 4: Specify the file format {#技巧4-指定文件格式}
**way** ： `filetype:文件格式 关键词`

**Example**:
```
filetype:avi 你懂的
```
Common file formats include `doc`, `pdf`, `ppt`, etc.

## Tip 5: Specify search in title {#技巧5-指定在标题搜索}
**way** ： `intitle:关键词`

**Function**: The searched keywords must appear in the title


## Tip 6: Specify search within content {#技巧6-指定在内容中搜索}
**way** ： `intext:关键词` 、 `allintext:关键词1 关键词2` 、 `inurl:关键词2`


## Tip 7: Use multiple search techniques together {#技巧7-多种搜索技巧叠加使用}
**Example**:
```
site:zhihu.com 前端 intitle:js
```
Use multiple techniques and keywords in a superimposed manner, separated by spaces.


## Things to note {#注意事项}
The symbols used in the above search techniques are all English symbols.
