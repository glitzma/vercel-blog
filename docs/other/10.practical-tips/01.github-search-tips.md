# GitHub advanced search tips {#github高级搜索技巧}

`in:name <关键字>`
 Warehouse name query with keywords

`in:description <关键字>`
 Warehouse description with keyword query

`in:readme <关键字>`
 README file with keyword query


<!-- more -->


`stars(fork): >(=) <数字> <关键字>`
 Query with keywords when the number of stars or forks is greater than (or equal to) the specified number

`stars(fork): 10..20 <关键词>`
 Keyword query with star or fork number between 10 and 20



`size:>=5000 <关键词>`
 Query with keywords that limits warehouses to be greater than or equal to 5000K

`pushed(created):>2019-11-15 <关键字>`
 Query with keywords updated or created after November 16, 2019

`license:apache-2.0 <关键字>`
 LICENSE is a keyword query for apache-2.0

`language:java <关键词>`
 Query with keywords in warehouse language Java



`user:<用户名>`
 Query a user's projects

`org:<组织名>`
 Query an organization's projects

***The above query conditions can be used in combination and separated by spaces**

```sh
# 示例1：搜索仓库名包含javascript，并且stars数大于1000的项目
in:name javascript stars:>1000

# 示例2：搜索描述中包含"小程序"，并且fork大于100，并且最近更新时间在2019-11-15之后的，并且使用开发语言为vue的项目
in:description 小程序 fork:>100 pushed:>2019-11-15 language:vue
```
