## 1\. First, let’s figure it out: What is uni-app? {#一、先搞清楚-uni-app-是什么}

**One sentence version:**

> uni-app = Use **Vue syntax**, write the code once, and publish it to **WeChat mini program / H5 / App / mini program for each platform**

### technical essence {#技术本质}

* Compiler: `@dcloudio/uni-cli`
* Framework core: **Vue 3 (recommended)**
* Rendering:

  * Mini program → Compile into corresponding platform DSL
  * H5 → Vue SPA
  * App → native shell (plus/nvue)


## 2\. Learning prerequisites {#二、学习前置}

If you meet the following 80%, you can **directly apply for uni-app**:

* ✅ HTML / CSS / JS（OK）
* ✅ ES6 (Promise / async / destructuring)
* ✅ Vue 3 Basics (**Key Points**)

  * `ref / reactive`
  * `computed / watch`
  * `props / emit`
  * `setup`
  * life cycle

👉 **You can learn Vue even if you don’t know it, but it will be twice as slow**


## 3\. uni-app core knowledge structure {#三、uni-app-核心知识结构}

### 1️⃣ Project creation & directory structure {#_1️⃣-项目创建-目录结构}

```bash
npx degit dcloudio/uni-preset-vue#vite my-uniapp
cd my-uniapp
npm install
npm run dev:mp-weixin
```

Core directory:

```txt
pages/            # 页面（路由即文件）
components/       # 组件
static/           # 静态资源
App.vue           # 全局入口
main.js
pages.json        # 路由 & 页面配置（非常重要）
manifest.json     # 平台配置
uni.scss          # 全局样式变量
```

👉 **Key points to understand:**

* No vue-router
* routes = `pages.json`
* The page must be registered


### 2️⃣ Page & Routing Mechanism {#_2️⃣-页面-路由机制}

```js
uni.navigateTo({
  url: '/pages/detail/index?id=1'
})
```

Commonly used APIs:

* `navigateTo`
* `redirectTo`
* `switchTab`
* `navigateBack`

Page life cycle (mini program flavor):

```js
onLoad()
onShow()
onHide()
onUnload()
```

📌 Frequently asked interview questions:

> What is the difference between `onLoad` and `onShow`?


### 3️⃣ Components & Styles (Differences from Vue) {#_3️⃣-组件-样式-和-vue-的差异}

#### components {#组件}

* Support Vue components
* **Cannot use DOM API directly**
* Not supported `window / document`

#### style {#样式}

* Default `rpx`
* Support `scss`
* **Style Isolation**

```css
width: 750rpx;
```


### 4️⃣ Data request & interface encapsulation (practical focus) {#_4️⃣-数据请求-接口封装-实战重点}

```js
uni.request({
  url: 'https://api.xxx.com/list',
  method: 'GET',
  success: res => {
    console.log(res.data)
  }
})
```

Recommended package:

```js
export const request = (options) => {
  return new Promise((resolve, reject) => {
    uni.request({
      ...options,
      success: resolve,
      fail: reject
    })
  })
}
```

📌 Compare axios:

* No interceptor (you have to block it yourself)
* Pay attention to platform differences


### 5️⃣ State management (Vuex/Pinia) {#_5️⃣-状态管理-vuex-pinia}

👉 **2024+ Recommended: Pinia**

```js
export const useUserStore = defineStore('user', {
  state: () => ({
    token: ''
  })
})
```

Storage:

```js
uni.setStorageSync('token', token)
```


### 6️⃣ Platform difference processing (high-frequency pits) {#_6️⃣-平台差异处理-高频坑}

```js
// #ifdef MP-WEIXIN
// 微信小程序代码
// #endif

// #ifdef H5
// H5 代码
// #endif
```

📌 You must know it, otherwise the project will explode

## 5\. Common pitfalls (avoid lightning in advance) {#五、常见坑-提前避雷}

- ❌ Using DOM API
- ❌ Forgot to register pages
- ❌ The page path is written incorrectly
- ❌ H5 is normal, the mini program reports an error
- ❌ use axios directly
- ❌ Abuse of global variables
