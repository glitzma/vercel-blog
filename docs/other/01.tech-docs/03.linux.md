##### 5. Partition {#_5-分区}

 Disk partitioning is dividing the disk into several logical parts using a partition editor\
 Once the disk is divided into multiple partitions, different types of directories and files can be stored in different partitions.
##### 6. mount point {#_6-挂载点}

- In order to make these partitions accessible in the Linux system, these partitions need to be mounted to the corresponding directories.
- In Linux, the directory is called a mount point.
- The process of linking directories and partitions together is called mounting
- / is the root directory and must be mounted on a partition. By default, all subdirectories will be written to this partition.
- All subdirectories under the same level directory can have their own independent storage space
- Required partitions
    - /root partition
    - Swap partition (swap partition, virtual memory, generally 2 times the memory, not more than 2G)
- Recommended partition
    - /boot (boot partition, 200M) separate partition to avoid the system being unable to start due to the partition being full.

##### 1.3.7 mv
- Move a file or rename it move
- mv [source file or directory] [target file]

When the second parameter type is a file, the mv command completes file renaming. It renames the given source file or directory to the given target file name.\
When the second parameter is the name of an existing directory, there can be multiple source files or directory parameters, and the mv command will move all the source files specified by each parameter to the target directory.When moving files across file systems, mv first copies and then deletes the original file, and the link to the file will also be lost.

```
# 将webdata 移动到/bin/usr/中
mv  webdata  /bin/usr/

# 将 /usr/lib/下所有的东西移到/zone/中。
mv    /usr/lib/*    /zone


# 是将lib下以txt结尾的所有文件移到/zone中。
mv    /usr/lib/*.txt    /zone

# 将文件temp.txt 修改名字为tempTest.txt
mv   temp.txt  tempTest.txt

```

`[options]`Main parameters (several important parameters)\
`-i`: Interactive operation.If the mv operation will cause overwriting of an existing target file, the system will ask whether to rewrite and require the user to answer "y" or "n" to avoid accidentally overwriting the file.\
`-f` : Interactive operations are prohibited.The mv operation does not give any instructions when overwriting an existing target file. After specifying this parameter, the i parameter will no longer have any effect. `- r` Instructs mv to recursively move all directories and subdirectories listed in the parameter.

### 6. Appendix {#_6-附录}
#### 6.1 System startup {#_6-1-系统启动}
##### 6.1.1 BIOS
- After the computer is powered on, the first thing is to read the boot program flashed into the ROM chip. This program is called (Basic Input/Output System)
##### 6.1.2 Hardware self-test {#_6-1-2-硬件自检}
- The BIOS program first checks whether the computer hardware can meet the basic conditions for operation. This is called "Hardware Self-Test" (Power-On Self-Test)
- If there is a problem with the hardware, the motherboard will beep with different meanings and the startup will be aborted.If there is no problem, the screen will display CPU, memory, hard disk and other information.
##### 6.1.3 Startup sequence {#_6-1-3-启动顺序}
- After the hardware self-test is completed, the BIOS transfers control to the next stage of the startup program.
- At this time, the BIOS needs to know which device the "next stage startup program" is stored in.
- The BIOS needs to have a ranking of external storage devices, and the device ranked first is the device that gives priority to transfer control.This sorting is called "Boot Sequence"
- The BIOS follows the "boot order" and transfers control to the storage device ranked first.
- At this time, the computer reads the first sector of the device, which is the first 512 bytes.If the last two bytes of these 512 bytes are 0x55 and 0xAA, it indicates that the device can be used for booting; if not, it indicates that the device cannot be used for booting, and control is transferred to the next device in the "boot sequence".
- The first 512 bytes are called the "Master boot record" (MBR)
##### 6.1.4 Structure of Master Boot Record {#_6-1-4-主引导记录的结构}
- The "Master Boot Record" is only 512 bytes, so it can't hold much.Its main function is to tell the computer where to find the operating system on the hard disk.
    - (1) Bytes 1-446: are used to record the startup information of the system and call the machine code of the operating system
    - (2) Bytes 447-510 (64 bytes): Partition table. The function of the partition table is to divide the hard disk into several areas.
    - (3) Bytes 511-512: Master boot record signature (0x55 and 0xAA)
##### 6.1.5 Partition table {#_6-1-5-分区表}
- Disk partitioning is dividing the disk into several logical parts using a partition editor
- Once the disk is divided into multiple partitions, different types of directories and files can be stored in different partitions.
- The "Master Boot Record" therefore must know which partition to transfer control to
- The length of the partition table is only 64 bytes, which is divided into four items, each item is 16 bytes.Therefore, a hard disk can only be divided into four first-level partitions, also called "primary partitions"
    - (1) The 1st byte: If it is 0x80, it means that the primary partition is the active partition, and control is transferred to this partition.Only one of the four primary partitions can be activated.
    - (2) Bytes 2-4: The physical location of the first sector of the primary partition (cylinder, head, sector number, etc.).
    - (3) The 5th byte: Primary partition type, such as FAT32, NTFS, etc.
    - (4) Bytes 6-8: The physical location of the last sector of the primary partition.
    - (5) Bytes 9-12: The logical address of the first sector of the primary partition.
    - (6) Bytes 13-16: The total number of sectors in the primary partition.
##### 6.1.6 Hard disk boot {#_6-1-6-硬盘启动}
- The control of the computer will be transferred to a certain partition of the hard disk.
- Of the four primary partitions, only one is active.The computer will read the first sector of the activated partition, which is called the "Volume boot record" (VBR).
##### 6.1.7 Operating system {#_6-1-7-操作系统}
- After control is transferred to the operating system, the operating system's kernel is first loaded into memory.
- Taking the Linux system as an example, first load the kernel under the /boot directory.After the kernel is loaded successfully, the first program to run is /sbin/init.It generates an init process based on the configuration file (/etc/initab for Debian systems).This is the first process after Linux starts. The pid process number is 1, and other processes are its descendants.
- Then, the init thread loads various modules of the system, such as window programs and network programs, until the /bin/login program is executed, the login interface jumps out, and the user enters the user name and password.

| Check status | `/usr/sbin/sestatus -v` |
| Temporary shutdown | `setenforce 0 `|
| permanently closed | `/etc/selinux/config SELINUX=enforcing改为SELINUX=disabled` |
