## Shell related knowledge {#shell相关知识}
### 1. shell basics {#_1-shell基础}
- The shell is a command line interpreter that provides users with an interface to send requests to the Linux kernel in order to run programs system-level programs
- Users can use Shell to start, suspend, stop or write some programs
- Shell is also a very powerful programming language, easy to write, easy to debug, and highly flexible.
- Shell is a scripting language for interpretation and execution. Linux system commands can be directly called in Shell.

- -e: Activate escape characters

### 2. variable {#_2-变量}
#### 2.1 What are variables {#_2-1-什么是变量}
- Amount that can vary
- Variables must start with a letter or underscore, and the name can only consist of letters, numbers, and underscores.
- Variable names cannot exceed 255 characters in length
- Variable names must be unique within the valid scope
- The default type of variables is string
#### 2.2 Classification of variables {#_2-2-变量的分类}
- string
- integer
- floating point
- date type
#### 2.3 User-defined variables {#_2-3-用户自定义变量}

- There cannot be spaces on the left and right sides of the equal sign

3.1.1 declare command
- Used to declare variable types
- declare [+/-] [option] variable name

| Options | Meaning |
| -- | -- |
| - | Set type attributes to variables |
| + | Cancel the type attribute of the variable |
| -a | Declare the variable as an array type |
| -i | Declare the variable as an integer |

```shell

c=$a+$b

declare -p c //显示指定变量的被声明的类型
//declare -i c="3"

//声明环境变量
declare -x kk=1
set | grep kk      //查看所有变量
env | grep kk      //只查看系统变量

declare -r x //只读
x=2  //bash: x: readonly variable
```

#### 4.4 Metacharacters {#_4-4-元字符}

`alias grep='grep --color=auto'`

| Metacharacter | Function | Example |
| -- | -- | -- |
| * | Matches the previous character 0 or any number of times | `grep 1* reg.txt`|
| . | Matches any character except newline | `grep . reg.txt`|
| ^ | matches the beginning of the line.For example, `^hello` will match lines starting with hello | `grep ^a reg.txt`|
| $ | matches the end of the line.For example, hello& will match lines ending with hello | `grep a$ reg.txt`|
| [] | Matches any character specified by the handle number, and only matches one character.For example, [aoeiu] matches any vowel, [0-9] matches any one digit, [a-z][0-9] matches two characters consisting of lowercase letters and one digit | grep ab[bc]c reg.txt|
| [^] | Matches any character except the characters in square brackets.For example, [^0-9] matches any non-numeric character,
| [^a-z] | Match any non-lowercase letter | grep a[^fg]c reg.txt|
| \ |Escape character, used to cancel the meaning of special symbols | grep \.$ reg.txt|
| {n} | means that the preceding character appears exactly n times.For example, [0-9]{4} matches 4-digit numbers, [1][3-8][0-9]{9} matches a mobile phone number | grep "a{1}" reg.txt|
| (n,} | means that the preceding character appears no less than n times. For example, [0-9]{2,} matches two or more digits | grep "a{1,}" reg.txt|
| {n,m} | means that the preceding character appears at least n times and at most m times.For example, [a-z]{6,8} matches 6~8 lowercase letters | grep "a{2,3}" reg.txt|

#### 4.8 sed command {#_4-8-sed命令}
- sed is a lightweight editor mainly used to select, replace, replace and add data.
- sed [options] '[action]' file name
- All actions must be enclosed in odd numbers
- The type is similar to batch vi operation

4.8.1 Action

| Parameter | Meaning Example |
| -- | -- | -- |
| a | Append, add one or more lines below each line or the specified line | sed '1a newline' score.txt|
| c | Line replacement, replace the entire original data line with the string after c | sed 'c newline' score.txt|
| s | String replacement, replace one string with another string, the format is "line range s/old string/new string/g" | sed '3s/lisi/lisisi/g' score.txt|
| i | Insert, insert one or more lines in the current line | sed '1i newline' score.txt|
| d | Delete the specified line | sed '1,2d' score.txt|
| p | Print, output the specified line | sed -n '2p' score.txt|

4.8.2 Options

| Parameters | Meaning | Examples |
| -- | -- | -- |
| -n | Generally, the sed command will output all data to the screen. If you add this option, only the processed lines will be output to the screen | sed -n '2p' score.txt|
| -e | Allows multiple sed editing commands to be applied to input data | sed -e 's/91/92/g;s/81/82/g' score.txt|
| -i | Use sed modifications to directly modify the edited file instead of outputting it on the screen | sed -i '1i newline' score.txt|
