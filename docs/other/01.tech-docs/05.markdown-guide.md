### Introduction {#简介}

`Markdown` is a lightweight markup language that allows people to write documents in a plain text format that is easy to read and write.

## 2\. Badge {#二、徽章}

#### what is a badge {#什么是徽章}

A badge is a small and exquisite icon, usually with relevant text for auxiliary explanation. It can monitor data, jump links, etc., and is full of expressiveness.

It is common on the `github` project homepage, but it not only appears on the `github` project homepage, but can appear anywhere where pictures can be displayed.



#### Use of badges {#徽章的使用}

* Used in `markdown`

```markdown
格式:
[![图片文字说明](图片源地址)](超链接地址)  # 即超链接内部嵌套图片

语法：
[![github](https://img.shields.io/badge/github-xugaoyi-brightgreen.svg)](https://github.com/xugaoyi)
```

## 5\. Text {#五、文本}

### paragraph {#段落}

Markdown paragraphs have no special format. Write the text directly. **Use 2 Tabs when you need to indent the paragraph**



### font {#字体}

```markdown
*斜体文本*
或 _斜体文本_
**粗体文本**
或  __粗体文本__
***粗斜体文本***
或 ___粗斜体文本___
```

*italic text*

_italic text_

**Bold text**

__Bold Text__

***Bold italic text***

___Bold italic text___



###  strikethrough {#删除线}

If you want to add a strikethrough to the text on the paragraph, you only need to add two wavy lines **~~** at both ends of the text. An example is as follows:

```markdown
~~BAIDU.COM~~
```



~~BAIDU.COM~~



### Underline {#下划线}

Underlining can be achieved through the HTML `<u>` tag:

```markdown
<u>带下划线的文本</u>
```

<u>Underlined text</u>



### text highlight {#文字高亮}

Text highlighting can highlight part of the text within a line, using a pair of backticks.

```markdown
`html` `css` `javascript`
```

`html` `css` `javascript`



### divider {#分隔线}

You can use more than three asterisks, minus signs, and underscores in a line to create a separator line, and there can be no other things in the line.You can also insert spaces between asterisks or minus signs.Each of the following writing methods can create a dividing line:

```markdown
***

*****

- - -

----------
```





***



### Footnote {#脚注}

Footnotes are additional explanations of the text.

```markdown
[^变量]
在文档结尾或其他位置給变量赋值：
[^变量]: 注明框内显示的内容

鼠标移到这里> [^哈喽]
[^哈喽]: 注明框内显示的内容
```

> Note: Not supported in some online previews

Move the mouse here> `[^哈喽]`

## 6\. List {#六、列表}

Use asterisk `*`, plus sign `+` or minus sign `-` as list markers:

```markdown

+ 第一项
+ 第二项

- 第一项
- 第二项
```



* first item
* Second item

### ordered list {#有序列表}

Use numbers followed by a ` .` sign to indicate

```markdown
1. 第一项
2. 第二项
```



1. first item

## 9\. Links {#九、链接}

Format:

```markdown
[链接名称](链接地址)

[链接名称](链接地址,可选的alt)

或

<链接地址>
```

Example:

```markdown
[百度](http://www.baidu.com,'百度')
```

[ Baidu ](http://www.baidu.com,'百度')

Directly display the link address:

```markdown
<http://www.baidu.com>
```

<http://www.baidu.com>



### variable link {#变量链接}

Links can be replaced by variables, with variable addresses attached at the end of the document or elsewhere:

```markdown
这个链接用 1 作为网址变量 [Google][1]
这个链接用 baidu 作为网址变量 [Baidu][baidu]

然后在文档的结尾或其他位置给变量赋值（网址）
  [1]: http://www.google.com/
  [baidu]: http://www.baidu.com/
```



This link uses 1 as the URL variable [Google][1]

This link uses baidu as the URL variable [Baidu][baidu]

[1]:http://www.google.com
[baidu]: http://www.baidu.com/

## 13\. Other techniques {#十三、其他技巧}

### Supported HTML elements {#支持的-html-元素}

Tags that are not covered by Markdown syntax can be written directly in HTML in the document.

Currently supported HTML elements are: `<kbd> <b> <i> <em> <sup> <sub> <br>` and so on, such as:

```markdown
使用 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Del</kbd> 重启电脑
```

Use <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Del</kbd> to restart your computer

<b>I use the bold font of the b tag</b>



### escape {#转义}

Markdown uses many special symbols to express specific meanings. If you need to display specific symbols, you need to use backslash escape characters:

```markdown
**未转义星号显示加粗**
\*\* 转义显示星号 \*\*
```

**Unescaped asterisks appear bold**
\*\* Escape and display asterisks \*\*



Markdown supports the following symbols preceded by a backslash to help insert ordinary symbols:

```markdown
\   反斜线
`   反引号
*   星号
_   下划线
{}  花括号
[]  方括号
()  小括号
#   井字号
+   加号
-   减号
.   英文句点
!   感叹号
```
