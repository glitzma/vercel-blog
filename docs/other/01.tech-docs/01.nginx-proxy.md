#### nginx advantages {#nginx优势}
- IO multiplexing: IO operations of multiple descriptors can be completed concurrently and alternately in one thread, reusing threads.\
    After Nginx is started, there will be a master process and multiple independent worker processes.\
    Receive signals from the outside world and send signals to each worker process. Each process may handle this connection.\
    The master process can monitor the running status of the worker process. When the worker process exits (under abnormal circumstances), a new worker process will be automatically started.\
    The number of worker processes is usually set to the number of machine CPU cores.Because more workers will only cause processes to compete with each other for the CPU, resulting in unnecessary context switching.\
    Using multi-process mode not only improves the concurrency rate, but also makes the processes independent of each other. If one worker process hangs up, it will not affect other worker processes.
- CPU affinity binds the CPU core and the nginx worker process together, allowing each worker process to be executed on one CPU, thereby reducing CPU switching and improving cache hit rate and performance.
- sendfile zero-copy transmission mode\
    Under the default configuration, after Nginx reads the local file, it will first read the hard disk file from the hard disk to the Nginx file buffer during network transmission. The operation process is: hard disk → kernel file buffer → application buffer.Then write the data in the Nginx file buffer to the network interface. The operation process is: application buffer → kernel network buffer → network interface.

    During the network transmission process, Nginx's local file went through the above two operations of reading and writing. Both operations stored the same data in the kernel buffer.In order to improve the efficiency of file transmission, the kernel provides zero-copy technology, which supports files to directly exchange open file handles in the kernel buffer without repeatedly copying the file content to the buffer. The process of the above two operations becomes: hard disk → kernel file buffer → kernel network buffer → network interface.

    Zero-copy technology reduces the number of file reads and writes and increases the network transmission speed of local files.The default size of the kernel buffer is 4096B.

#### cgi configuration file {#cgi配置文件}
- CGI is common gateway interface (common gateway interface)
- Web Server can pass dynamic requests to applications such as php, jsp, python and perl through the cgi protocol
- FastCGI is actually CGI with some extended functions. It is an improvement of CGI and describes a standard for transmitting data between client and Web server programs.
- The SCGI protocol is a replacement for the CGI (Common Gateway Interface) protocol. It is an interface standard for applications and HTTP servers, similar to FastCGI, but it is designed to be easier to implement.
- uwsgi is a web server that implements the WSGI protocol, uwsgi, http and other protocols

#### nginx configuration syntax {#nginx配置语法}

```bash
# 使用#可以添加注释,使用$符号可以使用变量
# 配置文件由指令与指令块组成,指令块以{}将多条指令组织在一起

            root   html;
            index  index.html index.htm;
        }
        error_page   500 502 503 504  /50x.html;
        location = /50x.html {
            root   html;
        }
    }
}
```

```bash
# zone名称 number限制的数量
Syntax: limit_req  zone=name [burst=number] [nodelay];
```

Case

```bash
limit_req_zone $binary_remote_addr zone=req_zone:1m rate=1r/s;

  location /{
      limit_req req_zone;
      # 缓存区队列burst=3个,不延期，即每秒最多可处理rate+burst个.同时处理rate个
```

$binary_remote_addr represents the remote IP address\
zone=req_zone:10m means that the size of a memory area is 10m, and the name is set to req_zone\
rate=1r/s means the request rate is 1 request per second

zone=req_zone means that the global setting corresponding to this parameter is the memory area of req_zone.

burst=3 indicates the length of the request queue\
nodelay means no delay

### Static resource web service {#静态资源web服务}
Static resources: Generally, the client sends a request to the web server. The web server retrieves the corresponding file from the memory and returns it to the client. The client parses and renders it for display.\
Dynamic resources: Generally, for dynamic resources requested by the client, the request is first handed over to the web container, and the web container connects to the database. After the database processes the data, the content is handed over to the web server, and the web server returns it to the client for parsing and rendering processing.

| Type | Type |
| -- | -- |
| Browser rendering | HTML, CSS, JS |
| Pictures | JPEG, GIF, PNG |
| Video | FLV, MPEG |
| Download file | Word, Excel |

####  CDN

The full name of CDN is Content Delivery Network, which is content distribution network.\
The CDN system can redirect the user's request to the service node closest to the user in real time based on comprehensive information such as network traffic and the connection and load status of each node, as well as the distance to the user and response time.Its purpose is to enable users to obtain the required content nearby, solve the congestion situation of the Internet network, and improve the response speed of users' access to the website.

### agency service {#代理服务}

The forward proxy is the client proxy, which acts as a proxy for the client. The server does not know the client that actually initiated the request.\
A reverse proxy is a server-side proxy that acts as a proxy for the server. The client does not know the server that actually provides services.

reverse proxy\
The actual operation mode of Reverse Proxy is to use a proxy server to accept connection requests on the Internet, then forward the request to a server on the internal network, and return the results obtained from the server to the client requesting a connection on the Internet. At this time, the proxy server appears as a server to the outside world.\
The role of reverse proxy:\
(1) Ensure the security of the intranet and prevent web attacks. Large websites usually use reverse proxy as the public network access address, and the web server is the intranet.

### load balancing {#负载均衡}

The use of clusters is a common means for websites to solve high concurrency and massive data problems.\
When a server's processing power and storage space are insufficient, don't try to change to a more powerful server. For large websites, no matter how powerful the server is, it cannot meet the website's continued growth in business needs.\
In this case, a more appropriate approach is to add a server to share the access and storage pressure of the original server.Through the load balancing scheduling server, access requests from the browser are distributed to any server in the application server cluster. If there are more users, more application servers will be added to the cluster so that the load pressure of the application server no longer becomes the bottleneck of the entire website.

upstream     

nginx forwards the request to a set of upstream service pools in the background\
Nginx can be configured to proxy multiple servers. When one server goes down, the system can still be available.

1. Polling(weight)

Specify the polling probability, and the weight is proportional to the access ratio, which is used when the performance of the back-end server is uneven.By default, when weight is not specified, the weight of each server is the same, and each request is assigned to a different back-end server one by one in chronological order. If the back-end server goes down, it can be automatically eliminated.

```bash
upstream bakend {
    server 192.168.1.10 weight=1;
    server 192.168.1.11 weight=2;
}
```

### cache {#缓存}
[nginx proxy cache](https://blog.csdn.net/dengjiexian123/article/details/53386586)

```bash
http{  
    # 缓存路径 目录层级 缓存空间名称和大小 失效时间为7天 最大容量为10g
    proxy_cache_path /data/nginx/cache levels=1:2 keys_zone=cache:100m inactive=60m max_size=10g; 
} 
```
 
- proxy_cache_path cache file path
- levels sets the cache file directory level; levels=1:2 represents a two-level directory
- keys_zone sets cache name and shared memory size
- inactive will be deleted if no one accesses it within the specified time.
- max_size is the maximum cache space. If the cache space is full, the resource with the longest cache time will be overwritten by default.

```bash
    if ($request_uri ~ ^/cache/(login|logout)) {
      set $nocache 1;
    }
    location / {
       proxy_pass http://mamingjuan;
    }
    location ~ ^/cache/ {
        proxy_cache cache;
        proxy_cache_valid  200 206 304 301 302 60m;   # 对哪些状态码缓存，过期时间为60分钟
        proxy_cache_key $uri;  # 缓存的维度
        proxy_no_cache $nocache;
        proxy_set_header Host $host:$server_port;  # 设置头
        proxy_set_header X-Real-IP $remote_addr;   # 设置头
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;   # 设置头
        proxy_pass http://127.0.0.1:6000;
    }
```

- proxy_cache tmp-test uses the corresponding cache configuration named tmp-test
- proxy_cache_valid 200 206 304 301 302 10d; cache httpcode 200... for 10 days
- proxy_cache_key $uri defines the unique key of the cache, and performs hash access through the unique key.
- proxy_set_header custom http header, used to send to the backend real server.
- proxy_pass refers to the path forwarded after proxy. Pay attention to whether the last / is required.

flag    
The flag bit is the type corresponding to the identification rule.

| flag | meaning |
| -- | -- |
| last | First match your own location, then create a new request through the rewrite rule and request the server again |
| break | Match your own location first, then the life cycle will end at the current location, and no subsequent matching will be performed |
| redirect | Returns 302 redirection yesterday, and will request this server in the future |
| permanent | Returns 301 permanent redirection, and will directly request the domain name after permanent redirection in the future |

```bash
location ~ ^/break {
     rewrite ^/break /test break;
     proxy_pass http://127.0.0.1:3000;
}

location ~ ^/last {
      rewrite ^/last /test last;
}

location /test {
      default_type application/json;
      return 200 '{"code":0,"msg":"success"}';
}

curl -vL http://192.168.20.150/redirect

location ~ ^/redirect {
 rewrite ^/redirect http://www.baidu.com redirect;
 rewrite ^/redirect http://www.baidu.com permanent;
}
```    
rewrite priority

- First execute the rewrite command in the server
- Perform location matching
- Then execute rewrite in location

priority in location

- The equal sign type (=) has the highest priority.Once a match is successful, no further matches are looked for.
- ^~type expression.Once a match is successful, no further matches are looked for.
- Regular expression types (~ ~*) have the next highest priority.If there are multiple location regular expressions that can match, the one with the longest regular expression will be used.
- Regular string match types match by prefix
